GoogleのAIモードのAPIでは、何がわかって、何がわからないのでしょうか。GoogleのAIモードの答えを見るツールを、実際に20回使って確かめた事実を整理します。

わかること（実測）

  • 答えの文章。20回すべて、文章（markdown）が返りました。長さは270〜6,357文字でした。
  • 引用元のリンク。15問では、引用元の名前、ドメイン、タイトル、URLが返りました。
  • 地域と言語の指定。日本・日本語で取れました。
  • 低い費用。1回$0.004。20回で$0.08でした。

わからないこと・できないこと（実測）

  • 引用元が出ない質問がある。20問のうち5問は、引用元のリンクが返りませんでした（20問の記事）。
  • 返るのはAIモードの答えだけ。20回とも、返ってきた項目は1つ（AIの答え）だけでした。通常の検索結果は、別のツール（C01）で取ります。
  • 毎回同じ答えとは限らない。この日の1回の結果です。聞くたびに変わることがあります。
  • あなたのサイトが引用されるための方法。データを見せるだけで、「こうすれば引用される」とは言えません。
  • 画面のAIモードと同じ見た目。返るのは文章と引用元のリンクで、画面の表示とは違います。

参考：返ってきた文章のようす

  • 20問のうち11問の文章に、「[ハイライトの開始]」「[ハイライトの終了]」という印が入っていました。
  • 15問の文章に、「[[1]](URL)」のような、文中のリンクが入っていました。

どう使い分ける？

  • ちょっと確認したいだけ → GoogleのAIモードの画面で質問すれば、無料で見られます。
  • 20個、30個のキーワードで、答えと引用元を記録して、表やCSVで残したい → このツールが向いています。

確認だけなら、まず画面で試してみてください。記録に残したくなったら、このツールを使ってみてください。

どうやって調べたか

  • 日付：2026年11月25日、地域と言語：日本、日本語
  • ツール：GoogleのAIモードの答えを見る（C02）（DataForSEOのAPIが、GoogleのAIモードの答えを返します）
  • 実測：20個のキーワードの記事のデータ（20回）
