「ChatGPTの画面で聞けば同じでは？」と思うかもしれません。ChatGPTの答えを見るツールは、ChatGPTのAPIを使っています。画面と同じではありません。ここでは、分かっている違いと、実測した事実を整理します。

違いを並べる

項目ChatGPTの画面このツール（API）
使うモデル画面や契約の種類で変わることがあります（OpenAIの公式で確認）gpt-4o-mini（実測：gpt-4o-mini-2024-07-18）
Web検索画面の設定や質問による使える設定。使うかどうかはChatGPTが決める（実測：40問のうち21問で検索）
あなたの履歴・設定ログインした人の履歴や設定が影響することがあります履歴のない、1回ごとの質問
結果の保存画面を見る表とCSVで保存できる
まとめて確認1問ずつ1問ずつ実行（結果をCSVで保存）
内部の検索ワード画面では見えない見える（実測：検索した31回で31個）
費用契約による（公式で確認）1回ごとの従量課金（実測：検索あり約$0.0272、検索なし約$0.0009）

ChatGPTの画面についての項目は、一般的な説明です。細かい仕様は変わることがあるので、公式で確認してください。

どう使い分ける？

  • 自分の画面で、ちょっと試してみたい → ChatGPTの画面で十分です。無料でも試せます。
  • お客さんがどう聞いても同じ状態で、答えを記録したい。内部の検索ワードも見たい → このツールが向いています。

確認だけなら、まずChatGPTの画面で聞いてみてください。記録として残したくなったら、このツールを使ってみてください。

このツールで、できないこと

  • 画面のChatGPTと、同じ答えを出すこと。モデルや条件が違います。
  • 同じ質問で、いつも同じ答えを出すこと。10回聞いて、店の組み合わせは3通りに分かれました（10回の記事）。
  • ChatGPTに載る方法を教えること。データを見せるだけで、「こうすれば載る」とは言えません。
  • Claude・Gemini・Perplexityの答え。それぞれ別のツール（C19・C20・C21）です。
