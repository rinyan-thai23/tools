# AI分析プロンプトの作り方（全ツールに広げるときの決まり）

実装済み（日本語・英語）：C24、C01、C25、C35、C41、C45。ひな形は `site/locales/ja.json` の `c24.ai_prompt` / `c24.ai_prompt_diff`。

## 仕組み
- `tool.json` に `"copy": true` を書いたツールだけ、「表をコピー」「入力を共有するURL」「行のコピー」「AI分析」が出る
- プロンプトの文は、ロケールの `<id>.ai_prompt`（分析）と `<id>.ai_prompt_diff`（前回との比較）。無ければ、AIの枠は出ない
- 使える差し込み：`{date}` `{country}` `{language}` `{n}`（行数）`{data}`（表）、比較用は `{prev_date}` `{prev_data}`
- 前回のデータは、そのブラウザの localStorage に、同じ入力・国・言語のときだけ保存（外へは送らない）

## 文の型（この順に書く）
1. **誰が読むか**：「〜な人が、〜を決めたいと思っています」（whoを先に）
2. **渡すデータ**：取得日、地域・言語、件数
3. **列の意味と、落とし穴**：そのツールで間違えやすい点を必ず書く（例：空欄は0ではない／CPCは広告の値／競合度はSEOの難しさではない）
4. **お願いしたいこと**：3〜4個。数字を使って理由を書かせる
5. **ルール**：渡した数字だけを使う／ない数字を作らない／推測は「推測です」と書く／中学生にも分かる言葉で／最後に表
6. **データ**：タブ区切りを ``` で囲む

## 広げる順番（案）
型が近いツールから数本ずつ。ツールごとに「誰が」「何を決めたいか」が違うので、プロンプトは1本ずつ書く。
1. 検索結果・順位：C03、C05、C07、C14（C01は済）
2. キーワード：C26、C36〜C40（C25・C35・C41は済）
3. 競合サイト：C34、C44、C46〜C49（C45は済）
4. AI：C18〜C23（回答の全文が長いので、データの量に注意）
