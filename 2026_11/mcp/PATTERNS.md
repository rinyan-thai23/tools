# MEO領域：成り立ちそうな型／そうでない型（2026-11-26 時点の判断）

根拠は、001〜002 の実データ7店（東京・埼玉・長野）。**店は私が選んだ。外の人の反応はまだゼロ。**だから、これは「どこから先に確かめるか」の仮説。

> 【2026-11-26 追記】需要と相場を調べた結果、**場所ごとの順位地図は、既存ツールが月数千円（Local Falcon 約$24〜、国内5,000円〜）で売っている。**下の「進める」は楽観的だった。差別化は地図そのものではなく「そのまま送れる1枚」「読み解き＋次の一手」。詳しくは `IDEAS.md`。

## 誰に売るか（売り先）
| 型 | 判断 | 理由 |
|---|---|---|
| 制作会社・MEO代行に診断メーカーを売る（002） | **要見直し**（元は「進める」） | 1診断の原価が約8円。1社が何十店に使う。届け方が「制作会社のいる場所」に絞れる |
| 店主に直接売る（001） | **単独では保留** | 1店ずつ届ける手間が大きく、単価も低い。ただし診断書は代行会社の営業資料として使えるので、LPは素材として残す |
| チェーン・複数店舗の本部に比較ボードを売る | **次に試す** | 同じ仕組みで店数が増えるほど価値が上がる。1社の売上が大きい。（未実験） |
| 商工会・自治体向けの地域診断 | **保留** | 1回の金額は大きいが、売る相手と手続きが重い。まだ手がかりなし |

## どの業種で使うか
| 型 | 判断 | 根拠 |
|---|---|---|
| 歯科・クリニック・整骨院・美容室（新規客がマップ検索から来て、1人の価値が大きい） | **進める** | 松本の歯科（口コミ15件対61件）、国分寺の美容室（星3.7対4.38）、新宿の歯科（18件対136件）で、はっきりした差が出た |
| 激戦区の飲食（新宿のラーメン・渋谷） | **条件つき** | 店の場所では1〜2位が多く、差は「口コミ数が桁違い」（126件対1,024件）としてしか出ない。診断が「口コミを増やして」の一言になりやすい |
| すでに強いお店（川越の整骨院：店の場所で1位） | **営業には向かない** | 診断が「大きな差なし」になる。見込み客として狙う意味が薄い。**代行会社が狙う店の選び方**が必要 |
| 出張・ネット専業など、場所を持たない仕事 | **対象外** | マップ順位の考え方が合わない（未検証の想定） |

## 街の密度
- 地方（松本）：上位20店が約1.3km、東京の住宅街・激戦区：約100〜400m。**格子の間隔は街ごとに自動で変える必要がある**（002で自動化済み）
- 間隔を合わせないと「圏外ばかり」に見えて診断が嘘になる。これは売り物の品質に直結する

## いま最も危ない前提（先に確かめる）
1. **順位が取るたびに変わる**（001で2回同じ条件を取ると、数字が少し違った）。月次の「変化」を売るなら、ノイズの大きさが分からないと成り立たない
2. **店の特定**が「店名＋地名の1件目」頼み。同名・チェーンで外れる
3. **競合の存在**：地図の順位を見せる既存ツール・サービスは既にあるはず（未調査）。違いが「営業資料としてそのまま送れる1枚」だけで足りるか
4. **「次の一手」を、制作会社が欲しがるか**（私が決めたルールのまま）
