# 015 競合の口コミから「選ばれる理由・嫌われる理由」を読む（スポット）

- 日付：2026-11-26　／　実費：**$0.03**（競合4店×100件）　／　状態：見本＋LPまで完了
- 区分：**A（DataForSEOだけで完結）**。競合選びは保存済みデータ（無料）、口コミ取得はDataForSEO、読み取りはAI（Claude）
- 一言：近所の競合の口コミ（1店100件）を読んで、選ばれる理由・嫌われる理由・自分の店だけの強み・次の一手を1枚にする。

## 誰の、どんな悩みか
開業・リニューアル・新メニューを考えている店主。「近所の競合は、何で選ばれ、何で嫌われているのか」を知りたいが、全部読む時間がない。
喜ばれる理由：ライバル店の客席でお客さんの会話を聞いてきたように、判断の材料が1枚で手に入る。

## 強引チェック
1. 悩みは本当にあるか：**仮説**。競合を知りたいのは自然だが、お金を払ってまで知りたいかは聞かないと分からない
2. APIなしで価値は成り立つか：成り立つ。価値の本体は「読んで、自店との違いを見つけること」。APIは口コミを集める材料
3. 既存より何が良いか：007の調査では、既存の分析ツールは自店中心に見える（競合比較の有無は未確認）
- **強引度：中**

## 何をどのようにしたか
1. **競合を選んだ**（無料）：国分寺・美容室の保存済み格子（002）から、多くの地点で上位に出る、口コミ100件以上の4店を選んだ（`data/competitors_selected.json`）
2. **口コミを取った**：1店あたり新しい順100件、計400件。$0.03（`tool/fetch_many.mjs`。0件が返ったら並び順を変えてやり直す作りにした。今回はやり直し不要）
3. **集計**（`tool/analyze.mjs`・費用0）：星の分布、時期別、返信率、話題のキーワード数
4. **AI（Claude）が読んだ**：高評価と低評価の本文を読み、選ばれる理由・嫌われる理由をまとめた
5. **見本レポート入りのLP**（`lp/index.html`）：店名・スタッフ名・投稿者名は伏せ（依頼店はA、競合はB〜E）

## 結果（国分寺・美容室）
| 店 | 直近6か月の口コミ | 星 | 返信率 | 低評価への返信 |
|---|---|---|---|---|
| A（依頼店・18件） | 4件 | 3.7 | 28% | 4/6 |
| B | 50件 | 4.6 | 99% | 5/5 |
| C | 73件 | 4.8 | 100% | 1/1 |
| D | 30件 | 4.9 | 16% | 1/1 |
| E | 35件 | 4.8 | 62% | 1/1 |
- **星1〜3の割合：A 39%（7/18）、競合 3%（13/400）**
- 競合の本文つき高評価344件のうち **51%が「カウンセリング・希望の汲み取り・相談・提案」に触れていた**（A：8件中3件）
- 「個室・半個室」への言及：**競合400件で0件、Aは18件中6件** → Aだけの強みになりえる
- 競合の嫌われる理由：接客の態度、要望の伝わり違い（仕上がりのズレ）、施術の失敗、匂い・換気
- 次の一手：予約時にイメージ写真と悩みを送ってもらう欄を作る

## 気づき・弱点
- **競合は「私たちが選んだ人気店」。** 口コミ100件以上に絞ったので、人気店のほうに偏る
- **「新しい順の100件」の期間が店で違う**（BとCは約1年、DとEは2年以上）。口コミが増えるペースの差は、そこから読んだ
- 話題の数え方はキーワードの目安。51%や「個室0件」は、数え方に依存する（`tool/analyze.mjs` の正規表現が根拠）
- 競合の口コミの「選ばれる理由」が来店につながるかは、口コミからは分からない
- 「Aだけの強み」は読み取りからの**仮説**。試さないと分からない
- 見本は国分寺の美容室だけ。他の業種・街では未確認
- **需要は未確認**（店主に聞いていない）

## 判断
- 区分A・強引度は中。**取得の原価はほぼ0（4店で約5円）**。価値の本体はAIの読み取りと、自店との比較
- 016（業種×街の不満・期待レポート）は、これの「業種全体」版。同じ作りで、競合を10〜50店にすれば作れる
