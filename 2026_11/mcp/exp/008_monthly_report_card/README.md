# 008 担当者がいない会社の「月1通信簿」

## 誰の・何を解決？
- 誰の：ネットの担当者がいない小さな店・会社の社長
- 困りごと：マップで見つかりやすいか、良くなったか悪くなったか、自分では分からない。報告をもらっても「順位が1つ下がった」で一喜一憂してしまう
- 届けるもの：月1枚の通信簿。**ゆれの範囲なら「変化なし」と言い切る**

## 作ったもの
`tool/card.mjs`：前回と今回の格子（5×5）を比べて、4項目（上位3位／上位10位／圏外の地点数／順位の中央値）を並べる。
004で測った「同じ条件でも順位は平均1.7〜2.4ずれる」を使い、地点数±3・中央値±2は「変化なし」。費用0（保存データだけ使う）。

## 試した結果（新規API 0円）
004の取り直しデータで、A（前回）とC（今回）を比較：
- 上位3位 1→1、上位10位 5→8、圏外 11→11、中央値 12→10 → **全項目「変化なし」**
- 生の数字だけなら「上位10位が+3！」と報告できてしまう。これが一喜一憂の元
- 本当の月次は、来月に取り直して初めて検証できる（今回は1日以内の比較なので、**ゆれを「変化なし」と判定できるかだけ**確認）

## 強引度チェック
- 需要：仮説。MEO月次レポートは既にあり（Local Falcon等）、差は「変化なしと言い切る」「社長の言葉で書く」点だけ
- 原価：1回 約$0.05（格子）〜 $0.1。月額に直すと原価は小さい。売値次第
- 強引度：低〜中（毎月の継続が価値なので月額と相性が良い）。ただし数字以外（何をすべきか）は002/021側の仕事
- 次：来月の再取得で、実際の変化が出るかを確認

## 注意
