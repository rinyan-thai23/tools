# 004 マップ順位の「ゆれ」の測定

- 日付：2026-11-26　／　実費：**$0.15**（国分寺×2回＋新宿×1回の取り直し、各25地点）　／　状態：完了
- 一言：月次の「変化」を売る案（008・009）が成り立つか確かめるため、**同じ条件で順位を取り直して、どれだけゆれるか**を測った。

## 誰の、どんな悩みか（この実験の立場）
お客さんではなく、**私たち自身の確認**。「先月より順位が上がりました」と報告しても、それが本物の変化か、ただのゆれか分からなければ、月次レポートで嘘を言うことになる。

## 何をどのようにしたか
1. 002で取った格子（国分寺の美容室・新宿のラーメン、各25地点）を「A」とした
2. 同じ地点・同じ言葉で取り直した（国分寺は続けて2回＝B・C、新宿は1回＝B）。`tool/noise.mjs`
3. 地点ごとに順位を比べ、「同じ順位だった地点数」「平均の差」「3位以内／10位以内の地点数の変化」などを集計
4. AとB・Cは**約1時間**の間隔（A：11:34、取り直し：12:36）。BとCは**数十秒**の間隔

## 結果
| 組 | 地点が全く同じ順位 | 平均の差 | 最大の差 | 上位3店の一致率 |
|---|---|---|---|---|
| 国分寺 B と C（続けて） | **24 / 25** | 0.07位 | 1位 | 0.92 |
| 国分寺 A と B（1時間後） | 12 / 25 | 1.8位 | 4位 | 0.72 |
| 国分寺 A と C（1時間後） | 12 / 25 | 1.7位 | 3位 | 0.69 |
| 新宿 A と B（1時間後・激戦区） | **1 / 25** | 2.4位 | **5位** | 0.79 |

見出しの数字（25地点のうち何地点か）の変化：
- 国分寺：10位以内 **5 → 8 → 8**（3位以内は1のまま、圏外は11のまま）
- 新宿のラーメン：3位以内 **2 → 8**（10位以内は17のまま）

## 分かったこと
- **続けて取ると、ほぼ同じ結果が返る**（24/25が同じ）。短い間に何回も取っても、平均してゆれを減らす役には立たない（おそらくGoogle側の一時保存）。**ゆれを減らすなら、時間を空けて取る必要がある**
- **1時間で、順位は平均1.7〜2.4位動く。** 激戦区のほうが大きく動く（25地点中24地点で順位が変わった）
- **見出しの数字（◯地点で3位以内）が、1時間でも2→8のように大きく動くことがある。**「先月は3地点、今月は5地点で上がりました」のような報告は、ゆれの範囲に入ってしまう
- 1日・1か月の間隔でどれくらい動くかは**未測定**（1時間より大きいはず）

## 判断（008・009への影響）
- **008（月1通信簿）：成り立つ。** 価値の本体は「今月やること1つ」で、順位の小さな変化には頼らない。ただし**「順位が上がった／下がった」を成果として報告しない**。見せるのは大きな差（口コミ数・競合との差）にする
- **009（月次マップ通信簿）：そのままでは危ない。**「変化」を売りにするなら、**時間をずらして3回取り、中央値や幅（例：3〜6地点）で出す**など、ゆれを前提にした作りが必要。強引度：中 → **中〜高**
- 診断書（002）：**1回きりの診断としては問題ない**が、「順位は目安」と書く注意書きを、より強く書く
- 次にやるなら：1日おきに3回取る実験（約$0.16/店）。ただし、売る前に必要かは、009を本当に作るかどうかで決める

## 気づき・弱点
- 店は2つだけ。国分寺と新宿で傾向は同じだったが、業種・街による違いは未確認
- 「Aの取得時刻」と「取り直しの時刻」しか比べていない。1時間という間隔は偶然
- 順位のゆれの原因（Google側のデータ更新・検索の揺らぎなど）は分からない
