# 018 インバウンドの声（多言語の口コミ）

## 誰の・何を解決？
- **誰の**：外国人のお客さんが来る飲食店・宿・観光施設のオーナー
- **困りごと**：口コミの大半が外国語。星は見えるが、中身（何が良くて何がイヤか）は読めていない
- **届けるもの**：外国語の口コミを日本語で読んで、「好かれている点／不満の点／すぐ直せること」を1枚にまとめたレポート

## やったこと（実測）
- 浅草のラーメン5店（口コミ200件以上）の新しい口コミ100件ずつ＝500件を取得
- 原価：**$0.0395**（地図検索 $0.002 + 口コミ 5店×100件）
- データ：`data/asakusa_ramen_reviews.json`（生）、`data/asakusa_ramen_summary.json`（言語別集計）

## 分かったこと
| 項目 | 数字 |
|---|---|
| 本文つきの口コミ | 360件（残り140件は星だけ） |
| うち外国語 | **334件（93%）** |
| 最多言語 | 英語 約7割、次いでスペイン語・韓国語・繁体字・タイ語 |
| 低評価（★3以下）の外国語 | 11件（3%）。ほぼ高評価 |
| オーナーの返信（外国語口コミ） | 179/334（54%）。日本語口コミは返信17/26 |

- 取得時に `language_code=ja` を指定すると、**本文はGoogleが日本語に機械翻訳したもの**が返る。元の言語は `original_language`、原文は `original_review_text`。→ 翻訳APIを別に用意しなくていい
- 本文のない口コミ（言語「不明」）が約3割。数だけ数えると外国語比率が崩れるので、本文ありで数える

## AIが読んだ内容（11件の低評価＋高評価の抜粋）
- 好かれる点：味、注文の分かりやすさ（多言語メニュー・タブレット注文）、個室ブース、早い提供、24時間
- 不満：行列・待ち時間（23件が言及）、塩辛い（7件）、ブースが窮屈（背の高い欧米人）、**最終入店時刻の運用トラブル**（21:10に断られた等・同一店で複数）
- すぐ直せる：最終入店の表示と実運用をそろえる／「待ち時間の目安」を外国語で出す／塩分の調整（「薄め」の選択肢）を案内する

## 強引度チェック
- 需要：**仮説**。ただしGoogleは返信用に翻訳を出すので「読めない」は半分は嘘。本当の価値は「数百件を要約して傾向にする」手間の肩代わり
- データ：A（DataForSEOだけ）。要約はAIが読む（API鍵なし・セッション内で実施→量産は未解決）
- 強引度：**中**。飲食以外（宿・体験）で需要が強い可能性。1店ずつ売るより、観光エリアの組合・DMOなど「面でまとめる人」向けが現実的
- 注意：浅草の一部の店は、外国語比率が極端に高い＝この需要が成り立つのは観光地だけ

## 次にやるなら
- 宿・体験施設で同じ集計をして、外国語比率と不満の質を比べる
- 観光協会に「エリア全体の声の集計」として見せて反応を聞く
