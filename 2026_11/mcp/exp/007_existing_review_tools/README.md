# 007 既存の口コミ管理・返信代行ツールの調査（調べものだけ・$0）

- 日付：2026-11-26　／　実費：**$0**（Web検索のみ）　／　状態：完了
- 一言：011（口コミ読解レポート）が売れる余地があるかを、既存のツール・サービスを調べて確かめた。

## 誰の、どんな悩みか（この調査の立場）
私たち自身の確認。「作ったものが、すでに安く売られていないか」を、作り込む前に知るため。

## 調べたこと（出典つき）
検索結果の多くは、**ツール業者・比較サイトの記事**。料金や効果は宣伝を含むので、目安として扱う。

### ① 口コミの「返信文を作る」AIツール：**すでに多い**
| 種類 | 例 | 料金の目安 |
|---|---|---|
| ブラウザ拡張 | MapBoost（[boxil](https://boxil.jp/service/50885/) など） | 無料（月5件）〜 月14,800円（返信無制限・10店舗まで） |
| 店舗支援SaaS | 口コミコム（mov）の「AI返信サポート」（[commercepick](https://www.commercepick.com/?p=39269)） | 料金は非公開（「ー」表示） |
| AI＋人の確認 | 商売繁盛AI（0120社・[記事](https://0120.co.jp/blog/shobai-ai-78/)） | 月49,800円。低評価（星1〜2）は人にアラート |
| 自作キット | Googleクチコミ返信 自動化キット（[BOOTH](https://booth.pm/ja/items/8129225)） | 個人販売。口コミが届くとAIが返信文を作ってLINEに届ける |
| 新サービス | AIが返信を提案（[Excite](https://www.excite.co.jp/news/article/AMP_465372/)）。複数店舗対応 | β版は無制限 |
- 相場の目安として、**月1万〜2万円**と書く販売ページもある（販売元の記載）。
- 比較記事も多く出ている（[atsoho](https://atsoho.com/blog/restaurant-review-reply-ai-tool-compare)）

### ② 口コミの「返信を人が代行する」サービス
- ココナラの出品例：月5件が基本、+5,500円/月で10件まで、+11,000円/月で20件まで（[ココナラ](https://coconala.com/services/2931638)）。追加分は1件あたり約700〜1,100円（私の計算）
- お名前.comの代行：口コミ返信のみのプランもあるが、初回契約は6か月（[お名前.com](https://www.onamae.com/business/product/235125/)）
- 実際に投稿してもらうには、Googleビジネスプロフィールの**管理権限を渡す**必要がある（[ランサーズ](https://www.lancers.jp/menu/detail/1259743)）
- 1件単価を明示した出品は少なく、**月額の件数制が主流**

### ③ 口コミを「分析」するツール：**ある。料金は多くが非公開**
- クチコレ（Sooon）：飲食・歯科・クリニック・宿泊・士業など。意見の抽出、感情分析、**改善策のレポート（PDF）**。FC・複数店舗にも対応（[ASCII](https://ascii.jp/elem/000/004/425/4425490/) 等）
- 口コミコム：集めた口コミ・アンケートをAIが解析し、傾向と課題を可視化
- MEOアナリティクス：店舗規模別の料金、新規は2週間無料。**口コミ件数の推移を店舗間で比較**
- mitsumonoAI：食べログなどの口コミURLを入れると、評価傾向と改善提案を出す
- **競合の口コミ比較**に対応しているかは、今回の検索では確認できなかった（会員限定の記事がある）

### ④ 返信の効果（需要の根拠）
- 「返信がないと来店率が4分の1に落ちる」という推計（[Forbes JAPAN](https://forbesjapan.com/articles/detail/94045)）。**出典は返信ツールの会社Mycatの分析**で、割り引いて見る
- 一方で、返信が**検索順位に与える影響は非常に小さい**とする記事（[口コミラボ・インプレス](https://netshop.impress.co.jp/node/9936)）。返信の主な効果は「見ている他の人への印象」
- **第三者による、返信の効果の調査は見つからなかった**

## 結論：011の売れる余地
| 部分 | 判断 | 理由 |
|---|---|---|
| 返信の**下書きを作る** | **単独では売れない** | 無料〜月数千円〜1.5万円のツールが多数ある。ここで勝負しない |
| 口コミを**分析して「型」を出す** | **競合あり（料金は不明）** | クチコレ・口コミコム等が既にある。ただし「契約するほどではない小さな店」「1回だけ知りたい」層は未確認 |
| **競合・業種全体の口コミ**を読む | **空いている可能性（未確認）** | 既存の分析ツールは、自店の口コミが中心に見える。競合比較の有無は要確認 |
| **スポット1枚**で売る（月額契約なし） | **未確認だが、隙間になりうる** | ツール系は月額契約が前提 |
- 011の**強引度を「低〜中」から「中」へ上げる**（返信下書きが売りだとすれば、強引）。
- **売りの軸を変える**：「返信文」ではなく、**「読み解き＋競合・業種全体との比較」**。返信の下書きはおまけにする。

## 気づき・弱点
- 調べたのは検索結果の範囲。有料の資料・会員限定の記事、各社の価格表は見ていない
- 料金の多くは非公開。実際に使うと違う可能性がある
- **店主に聞いていない。** 「返信が滞って困っているか」は、まだ仮説
