# 021 総合診断書（002の強化版）：5つの視点を1枚に

- 日付：2026-11-27　／　実費：**$0.054**（B店の地図のみ新規。他は保存済みデータを再利用）　／　状態：見本（2店）＋LPまで完了
- 区分：**A＋（DataForSEO＋無料のブラウザ＋AI）**
- 一言：002（制作会社向けの診断書）に、011・015・017・014の部品を足して、「総合診断書」として1枚にまとめられるかを確かめた。

## 誰の、どんな悩みか
制作会社・MEO代行の営業担当。見込み客の店に送る資料を、**1枚で、複数の視点から**作りたい。
喜ばれる理由：診断書そのものが営業のきっかけになり、**「取れなかった欄」も、提案の切り口になる**（サイトなし、料金非公開など）。

## 強引チェック
1. 悩みは本当にあるか：**仮説**（002と同じ。制作会社に聞いていない）
2. APIなしで価値は成り立つか：成り立つ。価値は「複数の視点を1枚に集めて、提案の切り口にすること」
3. 既存より何が良いか：順位ツール（月数千円）・口コミ分析ツール・サイト診断ツールは、それぞれ**1つの視点**。**5つを1枚にして、営業の切り口まで書く**ものは、未確認（未調査）
- **強引度：中**

## 何をどのようにしたか
1. **2店を選んだ**：A店＝見込み客役（口コミ18件・星3.7・**公式サイトなし：予約ポータルのみ**）、B店＝強い店（口コミ113件・星4.9・公式サイトあり）
2. **5つの欄を、既存の部品から集めた**（`tool/assemble_data.mjs`・費用0。結果は `data/report_data.json`）
   - ① マップ：002（A店は保存済み、**B店は新規に取得：$0.054・約1分**）
   - ② 口コミの読み取り：011（A店18件）・015（B店100件）
   - ③ 競合との口コミ比較：015（競合4店×100件）
   - ④ 口コミとサイトのズレ：017（B店）。**A店は取れなかった**
   - ⑤ 近所の料金比較：014（近所の競合5店の料金）。**A店の料金は取れなかった**
3. **欄ごとに「状態」を付けた**：自動／自動で集計＋AI／**取れなかった**／**一部だけ**。取れなかった欄は、**理由を書いて、そのまま表示**する
4. **AI（Claude）が、各欄の読み取り文・次の一手・営業の切り口を書いた**
5. **LP（見本）**（`lp/index.html`）：2店の診断書＋「1枚を作るのにかかるもの（実費・時間）」の表

## 発見
- **A店は、公式サイトがなく、予約ポータルのページだけだった。** ポータルは規約確認が必要なので読まない → **④サイトのズレ・⑤この店の料金が空になる**。小さなお店は、**ポータルだけで集客している店が多い**ことを示す。**これは、診断書の失敗ではなく、営業の切り口**（サイトがない＝サイト制作の提案）
- **「取れなかった欄」を正直に表示する設計**にした。無理に埋めない
- **店ごとに「次の一手」が1つ**（A：星1への返信／B：サイトに口コミの言葉を足す）と、**営業の切り口**が出た

## 自動／AI／手作業の区分
| 作業 | 区分 |
|---|---|
| 店の特定（店名→cid） | **手作業に近い**（同名・チェーンで外れる。005で改善予定） |
| 地図・口コミ・サイトの取得 | 自動 |
| 競合の選び方 | **手作業**（人気・近所の店を、保存データから選んだ） |
| 集計（星・返信率・話題・ズレ） | 自動 |
| 話題の辞書（業種ごと） | **手作業**（美容室用を作成。他業種は作り直し） |
| 料金の読み取り・表への整理 | **AI（手間が大きい。機械的な取り出しは誤りが出た）** |
| 読み取り文・次の一手・営業の切り口 | AI |
| 診断書のHTML化 | **手作業**（今回は私が書いた。テンプレート化が未実施） |

## 気づき・弱点
- **まだ「1コマンドで出る商品」ではない。** 取得は自動だが、**競合選び・料金の読み取り・文章・HTML化は、運営者のセッションの作業**。商品化には、ここを自動化（Claude API、テンプレート）する必要がある。**Claude APIのキーは「不要」と決めたので、当面は、運営者がセッションで作る「手作りの診断書」**になる
- **2店だけ。** 「ポータルのみの店」「サイトありの店」の2パターンは出たが、一般化はできない
- **料金欄は、取得率が低い業種がある**（美容室は約2割。014）。この欄は、業種を選ぶ
- 営業の切り口は、**私たちの見立て。制作会社が営業で使えるかは未確認**
- 口コミの引用は言い換えのみ。ポータル・競合サイトの文章は、リポジトリに置かない

## 判断
- **「5つの視点を1枚にする」形は、成立した。** 見せ方としては、002の単独の地図より、営業の切り口が具体的になる
- **ただし、自動化の壁は、「AIが読む」部分。** ここが、今後の商品化（および、特定業種の口コミ通信などの定期配信）の最大のボトルネック
- 次は、**制作会社に実際に見せて、反応を聞く**のが、いちばん情報が増える（外の人の反応はまだゼロ）
