# 聞き取りの進め方（1人10分）

**目的：** 作ったものが「欲しいか」を知る。**売り込みではない。** 感想より、「今どうしているか」「お金を払うか」を聞く。

## 守ること
- **褒めてもらおうとしない。** 「いいですね」は、弱い反応（社交辞令の可能性が高い）
- **過去の行動を聞く。** 「欲しいですか？」より、「最近、同じ困りごとで何をしましたか？」のほうが、本当のことが分かる
- **相手が話す時間を長く。** こちらは3割、相手は7割
- **お金の話は、最後に1回だけ。** 「いくらなら払いますか？」ではなく、「今、似たことにいくら払っていますか？」から入る
- 実在の店名・個人名が入る資料は、**見せない**（見せる用ページは、伏せ字になっている）

## 10分の流れ
| 時間 | やること |
|---|---|
| 0〜3分 | **相手の今を聞く**（下の「最初の質問」） |
| 3〜6分 | **見せる用ページを、1つだけ見てもらう。** 相手の種類に合うものを選ぶ（下の表） |
| 6〜9分 | **反応を聞く**（下の「見たあとの質問」） |
| 9〜10分 | **次の約束**（「もう1つ見てもらえますか」「◯◯さんを紹介してもらえますか」） |

## 相手の種類ごとに、最初に見せるもの
| 相手 | 最初に見せる | 次に見せる |
|---|---|---|
| 制作会社・MEO代行 | お店の総合診断書（/c/021/lp/） | 口コミとHPのズレ（/c/017/lp/）、診断メーカー（/c/002/lp/） |
| 店主（歯科・美容室・整骨院など） | 競合の口コミ読解（/c/015/lp/）または口コミ読解（/c/011/lp/） | 順位マップ（/c/001/lp/） |
| 業界の人（開業支援・メーカー・メディア） | 業種×街の口コミ調査（/c/016/lp/） | 3業種の比較（/c/020/lp/） |

## 最初の質問（相手の今）
**制作会社・代行の人**
1. 最近、新しいお客さん（お店）を見つけるとき、どうやっていますか？
2. そのとき、お店に最初に送る資料やメッセージは、何ですか？ 作るのに、どれくらいかかりますか？
3. 「口コミ」「順位」「サイト」の診断を、お客さんに出したことはありますか？ 何を使いましたか？ いくらでしたか？

**店主**
1. 最近、Googleマップの口コミを見ましたか？ 何のために？
2. 口コミの返信や、ライバル店の確認は、今、どうしていますか？ 誰が、週にどれくらい？
3. 集客や、ネットのことで、誰かにお金を払っていますか？ 月いくらですか？

**業界の人**
1. お客さん（患者・利用者）の本音を知りたいとき、どうやって調べていますか？
2. 調査にお金や時間を使ったことは？ いくら、どれくらい？

## 見たあとの質問（共通・最大5つ）
1. **これを、あなたの仕事で使う場面は、ありますか？** ある／ない／分からない（その理由は？）
2. **一番役に立ちそうな部分は、どこですか？ 逆に、いらない部分は？**
3. **足りないものは、何ですか？**（これがあれば使う、というもの）
4. **誰に送りますか？／誰に見せたいですか？**（具体的な名前や会社の種類）
5. **（最後に1回だけ）今、似たことにかけている費用と比べて、これはいくらなら、試してみようと思いますか？** 金額が出なければ、「高い／安い／分からない」でよい

## 反応の見分け方
| 強い反応（買う可能性が高い） | 弱い反応（社交辞令の可能性） |
|---|---|
| 具体的な金額を言う | 「いいですね」「すごいですね」だけ |
| 「うちのお客さんの◯◯店に送りたい」と店名を出す | 「便利そうですね」 |
| 「いつから使えますか？」と時期を聞く | 質問がない |
| 紹介・次の約束をしてくれる | 「検討します」 |
| 資料を保存・スクショしたがる | |
| **「いらない」と、理由を言ってくれる**（これも、とても大事な反応） | |

## 合格ライン（1つの案について、7日後に判断）
- **3種類の相手 × 各3人（合計9人）** に見せるのが目標（まず、制作会社3人だけでも可）
- **採用候補：** 見せた人のうち、**2人以上が強い反応**（金額、店名、時期、紹介のどれか）
- **見直し：** 強い反応が0人 ＆ 「いらない」の理由が共通 → 案の中身を直す（誰のためか、何を解決するか）
- **保留：** 強い反応が1人 → もう3人に見せる
- 「いらない」の理由は、**INDEXの「メモ」に書く**（次の案の材料になる）
