# 022 外の反応を取る準備（聞き取りキット）

- 日付：2026-11-27　／　実費：**$0**（APIは使っていない）　／　状態：準備完了。**聞き取りは、運営者が行う**（AIにはできない）
- 区分：—（データの案ではなく、「案を選ぶための準備」）
- 一言：作った案を、**本当に買うかもしれない人に見せて、反応を取る**ための準備物。

## なぜ必要か（たとえ話）
これまでは、料理の試作を、**作った私（AI）だけが食べて、点数をつけて**きた（INDEXの点数は、AIの自己採点）。本当に食べる人に、**一口食べてもらわない**と、「売れる料理か」は分からない。
**外の人の反応が、いちばん確かな点数**。ここまで16本近く試作したが、**外の反応は、まだゼロ**。

## 何を作ったか
| 準備物 | 中身 | 場所 |
|---|---|---|
| **見せる用ページ** | 伏せ字のLPだけを、相手の種類（制作会社／店主／業界）別に並べた1ページ。**このURLを送れば、他のページ（店名つきの生データ）に迷い込まない** | `/show/`（`show/index.html`） |
| **聞き取りの進め方** | 1人10分の流れ、最初の質問、見たあとの質問（5つ）、強い反応・弱い反応の見分け方、**合格ライン** | `kit/interview_guide.md` |
| **声のかけ方** | 相手の種類ごとのメッセージひな形（短く、売り込まない） | `kit/outreach_messages.md` |
| **記録シート** | 日付・相手・見せたもの・反応（相手の言葉のまま）・強い反応・いらない理由・次の約束・判定 | `kit/feedback_log.tsv` |

## 合格ライン（1つの案について、7日後に判断）
- **採用候補：** 見せた人のうち、**2人以上が強い反応**（具体的な金額・店名・時期・紹介のどれか）
- **見直し：** 強い反応が0人 ＆ 「いらない」の理由が共通 → 案の中身を直す
- **保留：** 強い反応が1人 → もう3人に見せる
- 「いらない」の理由は、**INDEXの「メモ」に書く**

- **強引度：低**（案の評価を、AIの自己採点から、外の反応に置き換えるため）

## 運営者がやること（私にはできない部分）
1. **誰に聞くかを決める**（知り合いの制作会社3人、店主3人、業界の人3人）
2. **`kit/outreach_messages.md` のメッセージを送る**（URLは `https://lab.byokkit.com/show/`）
3. **10分話す**（`kit/interview_guide.md` の流れ）。**相手が話す時間を長く**
4. **`kit/feedback_log.tsv` に、反応を相手の言葉のまま記録**する（またはメモを私に渡せば、私が整理する）
5. **7日後に、私に記録を渡す** → 私が、INDEXの「外の反応」「判定」に反映し、採用候補・見直し・保留を決める

## 気づき・注意
- **見せる用ページは、パスワードなし。** URLを知っている人は、全ページを見られる（生データの店名つきページも、URLを知っていれば開ける）。**店名つきのページのURLは、送らない**
- **お金の話は、最後に1回。** 先に聞くと、「いいですね」で終わりやすい
- **反応が薄い（いらない）ことも、成果。** 20本の区切りで、「何を作らないか」を決められる
- 聞き取りの相手には、**実在のお客さんの情報（店名・個人名）が入っていない**ことを伝える

## 20本の区切りとの関係
- 20本のうち、**この1本（022）で、「何を聞くか」が決まる。** 残り4本（005・006・018・014の追加業種・008）は、**聞き取りの結果を見てから、選び直してもよい**
- 区切りのあとの「既存ツールの公開・熟考」にも、**外の反応**が材料になる
