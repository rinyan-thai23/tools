# 003 AIに聞かれたとき、会社名は出てくるか（AI概要への掲載チェック）

- 日付：2026-11-26　／　実費：**$0.10**　／　状態：試験1回で、日本では保留
- 一言：ChatGPTやGoogleのAI回答に、会社名やドメインが出てくる回数を調べて売る案（事業案3）。

## 誰の、どんな悩みか
「AIで探す人が増えた」と感じている中小企業の経営者や採用担当。AIの回答に自社が出るか知りたい。
喜ばれる理由：検索順位とは別の「AIの中での見え方」を、数字で見せられる。

## 何をどのようにしたか
1. 使えるAPIを探した：`ai_optimization/llm_mentions/*`（`target_metrics_lite` など）。料金はドキュメント上は価格ページ参照で、叩く前に分からなかった
2. 日本で使えるプラットフォームを確認（無料）：`/v3/ai_optimization/llm_mentions/locations_and_languages` → 日本(2392)は **`google`（AI概要）のみ**。`chat_gpt` は米国など一部の国だけ
3. `chat_gpt` で日本を指定して叩く → 40501エラー（費用0）
4. `google` で、対象サイトと同業2社の3ドメインを1回で調べた → **3社とも0件**。費用 $0.10（`target_metrics_lite`）

## 結果
- 日本の小さなBtoB会社は、Google AI概要への掲載が0件だった。ChatGPTは日本では取れない
- 1回$0.10は、他のAPI（$0.01〜0.05）より高い

## 気づき・弱点
- 複数ドメインを1回で投げた時に、「どれか」か「全部」かの扱いが未確認。0件が本当に「どの会社も出ていない」かは言い切れない
- 「0件」だけでは、社長に出せるレポートにならない
- 米国向けの会社なら、ChatGPTとGoogle両方が取れるので成り立つ可能性はある（未実験）

## 判断
日本では**保留**。再開するなら、1社だけで取り直して確認（約$0.10）、または米国向けの事例で試す。
