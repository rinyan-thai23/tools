# 002 MEO診断メーカー（制作会社・MEO代行向け）

- 日付：2026-11-26　／　実費：**約$0.108**（店探し$0.002＋診断2回$0.052×2）　／　状態：道具＋見本＋LPまで完了
- 一言：店名とキーワードを入れると、御社名入りの「Googleマップ見え方診断」が1枚できる。営業のきっかけに送る。

## 誰の、どんな悩みか
小さな制作会社・MEO代行の営業担当。見込み客のお店に、きっかけになる資料を送りたいが、手作業の診断は1件30分以上かかる（※所要時間は想像で、未確認）。
喜ばれる理由：診断書そのものが「営業メールを開いてもらう理由」になる。001を、売る側の道具にしたもの。

## 何をどのようにしたか
1. **001の仕組みを部品にした**：`lib/mcp.mjs`（MCP接続）と `lib/grid.mjs`（地図順位）に切り出し
2. **見込み客役の店を選ぶ**：国分寺駅付近で「美容室」を1回検索（$0.002）。上位20店から、順位が中ほど（11位）で口コミが少ない `newi国分寺` を選んだ（代行会社が狙いそうな店）
3. **診断メーカーを作る**（`tool/generate.mjs`）。入力は `tool/config.sample.json`：店名＋地名・キーワード・会社名・伏せ字の有無
   - ① 店名＋地名で全国検索 → 1件目をその店とみなして座標・口コミ・写真・星・電話などを取得
   - ② その店を中心に 5×5=25地点の順位を取得
   - ③ 集計（3位以内／10位以内／圏外の地点数、上位店との比較、プロフィールの有無）
   - ④ **次の一手を1つ**、ルールで選ぶ（下記）
   - ⑤ 1枚のHTML（`diagnosis.html`）と数値（`diagnosis.json`）を出力
4. **取得結果は `data/` に保存**：文面やルールの調整は、お金をかけずに何度でもやり直せる
5. **LPを作る**（`lp/index.html`）：営業担当向け。悩み→診断書の実物→使い方（メール文面つき）→料金のイメージ→FAQ。実物は画像で埋め込み
6. **メール文面のひな形**（`sample_output/sales_email.txt`）。「順位が上がる」とは書かない注意つき

## 「次の一手」の選び方（`generate.mjs` にそのまま書いてある順）
1. オーナー確認が未完了なら、それ  2. 口コミが上位店の中央値の半分未満なら、口コミ  3. 写真が半分未満なら、写真
4. 星が上位店の平均より0.4以上低いなら、低評価の口コミへの対応  5. 未登録の項目があれば、それ  6. どれも無ければ、返信

## 結果（見本：国分寺・美容室）
- お店のまわり25地点のうち、3位以内1・10位以内1・**圏外23**。店のごく近くでしか見えていない
- 上位店（52店）との比較：口コミ 18件 対 22件、写真 35枚 対 15枚（差なし）。**星が 3.7 対 4.38**
- 最初に作ったルールは星の差を見ておらず、次の一手が「追加カテゴリの登録」になってしまった → 星のルールを足して修正（この過程が上の4番）

## 気づき・弱点
- **店の特定が不安定**：「店名＋地名」の1件目を採用している。同名・チェーン店では別の店になりうる。本番では、住所か地図のリンクで確認する手順が必要
- 見本は**1店だけ**の確認。業種・地域を変えたときにルールが妥当かは未確認
- 「上位店」は、25地点のどこかで3位以内に入った店。地域や業種で性質が変わる
- 診断ルールは自分たちで決めたもの。**制作会社が欲しい形かは未確認**
- 費用は1診断 約8円だが、所要時間・MCP経由のトークン量は、この回は測っていない
