# 017 口コミとHPのズレ診断（旧：口コミから作るHP素材）

- 日付：2026-11-26　／　実費：**$0.008**（サイトのアドレス取得4回。口コミは015の100件×4店を再利用）　／　状態：見本＋LPまで完了
- 区分：**A＋（DataForSEOに、無料のブラウザ表示を足した）**。Firecrawl・Apify等の有料ツールは使っていない
- 一言：Googleマップの口コミ（お客さんの言葉）と公式サイト（お店の言葉）を突き合わせて、「口コミで褒められているのにサイトに書いていない強み」を見つけ、サイトの文章案にする。

## 誰の、どんな悩みか
**制作会社：** 見込み客のお店のサイトと口コミを突き合わせた診断が、営業の入口になる。　**店主：** サイトを作り直すとき、何を書くか分からない。
喜ばれる理由：お客さんが実際に使っている言葉で、強みを書ける。

## 強引チェック（最初の案を見直した）
- **最初の案（口コミ → HPの文章を作る）は、魅力が薄い。** AIで誰でもできる。自店の口コミと自店のHPだけで完結する（運営者の指摘）
- **そこで、ロジックを変えた：「お客さんの言葉」と「お店の言葉」の「ズレ」を見つける。** 「口コミで多いのに、サイトに無い／薄い」「サイトで推しているが、口コミに出ない」を、数字で出す
1. 悩みは本当にあるか：**仮説**。サイトと口コミのズレを知りたい人がいるかは、聞かないと分からない
2. APIなしで価値は成り立つか：成り立つ。ただし**ズレを数える材料**（口コミ・サイトの文章）が要る
3. 既存より何が良いか：口コミ分析ツールは口コミだけ、サイト診断ツールはサイトだけを見る。**両方を突き合わせる**ものは未確認（未調査）
- **強引度：中**（最初の案より下がった）

## 何をどのようにしたか
1. **口コミ**：015で取った100件×4店を再利用（$0）
2. **サイトのアドレス**：`serp/google/maps/live/advanced`（店名で検索して `url` を取る）：4店で$0.008。**4店のうち、アドレスが取れたのは3店**（1店はGoogleマップにサイトの登録がない）
3. **サイトの文章**：
   - 最初は普通の取得（curl）＋タグ除去（`tool/extract_text.mjs`）→ **JavaScriptで表示するサイトでは文字が少ない**（1店は82文字）
   - **ブラウザ（Playwright・環境に入っている・無料）で表示して、見える文章を取り出す**（`tool/render_text.cjs`）。同じサイト内のリンクを6ページまでたどる
4. **突き合わせ**（`tool/gap.mjs`・費用0）：16の話題について、高評価の口コミ本文で出る割合と、サイトに出る回数を数え、ズレを分類
5. **AI（Claude）が、ズレから文章案**（キャッチコピー・紹介文・FAQ）を作った。事実と違うことを書かないよう、確認欄を入れた

## 結果（国分寺の美容室）
| 店 | サイト | ズレ |
|---|---|---|
| B（グループ運営） | 6ページ・約3,200文字。**会社案内（採用中心）で、お客さん向けの強みが少ない** | 口コミで「丁寧・安心」84%（サイト1回）、「話しやすい」74%（2回）、「リピート」45%（1回）、「希望を汲み取る」42%（2回）、**「カウンセリング」38%（0回）**、「駅近」21%（0回） |
| A（ショート専門） | 6ページ・約5,400文字。**カット・ショートを前面に** | **一致：** カット71%（13回）、ショート44%（6回）。**ズレ：** 「丁寧・安心」26%（0回）、「リピート・長く通う」32%（0回） |
| （人気店） | Googleマップにサイトの登録なし | 口コミ（半年で50件）だけで選ばれている |
- 「サイトで推しているが、口コミに出ない」は、今回の基準（口コミ4%未満・サイト3回以上）では出なかった。ただしAは、髪質改善・カラーをサイトで13〜14回書くのに、口コミでは15%ずつ（お店が押すメニューと、お客さんの評価の点は少し違う）

## 気づき・弱点
- **2店だけ。** 傾向は言えるが、一般化はできない
- **話題の数え方は、キーワード（正規表現）の目安。** 「丁寧」のような広い言葉は多く出る。辞書は美容室用で、他の業種は作り直す
- **サイトの文章の取り方：** ブラウザ表示で取れたのは6ページまで。**ログインが要るサイト・画像だけのサイト・ボット拒否のサイトは、取れない可能性がある**
- チェーンの共通サイト（EARTH）は、他店の文章が混ざって使えなかった（61,000文字）。**サイトが「その店のもの」かの判定が要る**
- **「口コミの言葉をサイトに使うと集客が増える」かは、確かめていない**
- 口コミの転載は、規約・許可の確認が要る。**診断は、言い換えと割合だけを使う**

## 判断
- **最初の形（口コミ→HPの文章）は、価値が薄いので作らない。** ズレ診断の形なら、**制作会社への営業資料**（002の診断書に「口コミとサイトのズレ」の欄を足す）として面白い
- 費用：1店あたり約$0.01（約1.5円）。Firecrawl等の有料ツールは不要（Playwrightで足りた）
