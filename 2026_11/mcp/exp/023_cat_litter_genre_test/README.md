## 測ったもの（費用：DataForSEO $0.0153 ＋ Apify 約$0.005）
`tool/probe_genre.mjs "<キーワード>" <名前>` で、Amazon検索→Googleショッピング検索→口コミ（最大3商品）を一括で測る。

| 項目 | 結果 |
|---|---|
| Amazon「猫 自動トイレ」 | 104商品。自動トイレ**本体**は66（残りは交換袋・消臭剤など消耗品）。販売数の目安あり36、星の中央値4.1、価格の中央値約2.4万円 |
| Googleショッピング | 83商品、gidあり50、口コミありは42（合計1.5万件）。ただし**本体は26商品、gidあり11、口コミありは5**で、各5〜6件と薄い |
| Google口コミの取得 | 上位3商品のうち取れたのは1つ（猫砂シート1,225件中40件）。2つは0件（課金される） |
| Amazon要約（Apify） | 本体5商品中4商品で「お客様の声」と項目別の言及数が取れた。1商品は要約なし |

## 分かったこと
- **この商品は、Amazonが主戦場。** Googleショッピングの口コミは本体では薄く、頼れない。
- Amazon要約で見えた不満の項目：砂の飛散(21)・臭い(19)・機能性(12)・サイズ(7)（Neakasa）、掃除のしやすさ(25)・動作(20)・消臭効果(15)・砂の量(11)・体重計測(8)（PETKIT）、機能性(83)・価格(47)（PetSnowy）。
- 総評価3,000件超の商品でも、★1は15〜17%。
- 注意：「自動トイレ」で検索すると消耗品が混ざる。本体だけに絞る（タイトルに自動＋トイレ、シート・砂・袋を除く）。
- 注意：Amazon要約の「箱の種類」が違う商品が混ざる（Neakasaの要約が「ゴミ箱」と書かれている）ので、要約の主語は確認が必要。

## 結論
このジャンルは、Amazon要約（約$0.01/商品）＋市場地図（Amazon検索）で十分に作れる。不満の本文は、Googleショッピングでは取れないので、Amazonの星★1〜2絞り（1件$0.006・10件ずつ）で補う。
