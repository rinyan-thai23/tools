# 020 口コミの不満の型：3業種（歯科・美容室・整骨院）の比較と、自動分類の精度確認

- 日付：2026-11-26　／　実費：**約$0.27**（美容室$0.111＋整骨院$0.113＋業種カテゴリの確認$0.049。歯科は016のデータを再利用）　／　状態：見本＋LPまで完了
- 区分：**A（DataForSEOだけで完結）**。取得・集計は自動、「型」の読み取りはAI（Claude）
- 一言：016の仕組みが、他の業種でも動くかを確かめた。あわせて、**不満の「型」を辞書で自動分類できるか**を試した。

## 誰の、どんな悩みか
016と同じ（開業支援・メーカー・業界コンサル・メディア）。**業種をまたいだ比較**ができると、「業種ごとの違い」と「共通の落とし穴」が分かり、1業種ずつの調査より使い道が広がる。

## 強引チェック
1. 悩みは本当にあるか：**仮説**（変わらず。業界の人に聞いていない）
2. APIなしで価値は成り立つか：成り立つ（読み取りが価値の本体）
3. 既存より何が良いか：3業種を同じ作りで比べられる点。既存の口コミ分析ツールは業種横断の調査レポートを作るものではなさそう（007。未確認）
- **強引度：中**

## 何をどのようにしたか
1. 業種カテゴリの候補を確認（`probe.mjs`・約$0.012/回）：東京中心20km・評価4以上・口コミ10件以上で、**美容室 `hair_salon` 5,644店、整骨院系 `chiropractor` 971店**（`osteopath` 325店は「Bonesetting house」で別カテゴリ）
2. 016の `market_reviews.mjs` を、**設定ファイルだけ変えて**実行（`tool/config.tokyo_hair.json`・`config.tokyo_chiro.json`）。コードの変更は不要
3. 各24店の口コミを取得・集計（美容室523件・49秒・$0.111、整骨院534件・57秒・$0.113）。**整骨院では0件で返ったタスク2件が、自動でやり直されて成功した**
4. 読み取りパケット（星1〜2の無作為抽出）を、AI（Claude）が読み、不満の型にまとめた
5. **型の辞書（`tool/taxonomy.json`）を作り、全件を自動で分類**（`tool/classify.mjs`）。私の読み取りと比べて、精度を確認した
6. 3業種を並べたLP（`lp/index.html`）

## 結果（3業種の比較）
| 項目 | 歯科 | 美容室 | 整骨院 |
|---|---|---|---|
| 院・店 / 口コミ | 32 / 606 | 24 / 523 | 24 / 534 |
| 新しい順の星1〜2の割合 | 12.3% | 6.4% | 4.0% |
| 星1〜2への返信率 | 31% | 50% | 66% |
| 本文なしの割合（新しい順） | 19% | **34%** | 16% |
| 星1〜2の本文に「予約・待ち」（星4〜5では） | 24%（12%） | 21%（9%） | **35%（6%）** |
| 星1〜2の本文に「料金・費用」（星4〜5では） | 19%（7%） | 21%（7%） | **50%（20%）** |

**AIが読んだ不満の型（目安）**
- 歯科（50件を読んだ）：受付・電話の応対 約28%／治療の結果・見落とし 約28%／説明不足 約16%／待たされる・予約 約12%／医師の態度 約10%／HPと実際の食い違い 約6%
- 美容室（34件）：**希望と違う仕上がり 約45%**（写真を見せたのに違う、など）／接客・態度 約26%／要望が伝わらない 約16%／担当・店の変化 約12%／待たされる・予約 約10%／ダメージ・失敗 約10%
- 整骨院（24件）：態度・接客 約25%／施術の中身・効果 約25%／営業・勧誘 約17%／待たされる・予約 約17%／料金 約12%／担当・常連優先 約8%

**言えること：** 3業種とも、不満の上位2〜3つに**「応対」（態度・電話・待たせ方）**が入る。業種ごとの固有の不満は、歯科＝治療後の結果・見落とし、美容室＝希望と違う仕上がり、整骨院＝料金・勧誘・待たされ。

## 自動分類（辞書方式）の精度（無作為に34件を確認した結果）
| 業種 | 辞書で分類 | 確認した結果 |
|---|---|---|
| 歯科（14件） | 型に入らない26% | **取りこぼしが多い**（虫歯の見落とし、価格、「予約が取りにくい」などを拾えない）。ラベルが付いた7件のうち、正しいのは約5件。**実際に型のある13件のうち、拾えたのは約7件（約54%）** |
| 美容室（10件） | 型に入らない5% | **拾いすぎ**（1件に複数の型が付き、「無断撮影」が「仕上がりのズレ」に入った）。拾えるが、精度は約65%の印象 |
| 整骨院（10件） | 型に入らない12% | おおむね正しいが、「**営業間に合ってます**」という文が「営業・勧誘」に入るなど、**言葉の意味を取り違える**誤りがあった |
- **結論：キーワードの辞書だけでは、全件の自動分類は精度が足りない。** 概算としては使えるが、製品の数字には使えない。
- **私の読み取り（AI）の件数も、1件が複数に入る目安**で、再現性は未確認
- **対策：** AI（Claude API）で全件を分類し、辞書は下ごしらえ（粗い絞り込み）に使う。**Claude APIを呼ぶには、キーを環境に登録する必要がある**（いまの環境には無い）

## 気づき・弱点
- **「同じコードを設定だけ変えて別業種で動いた」**：自動化の再利用性は確認できた。ただし、**話題のキーワード辞書は業種ごとに作り直す**必要がある（今回は私が読んでから作った）
- **評価4以上の店に限った比較。** 業種全体の不満ではない。院・店の数は各24〜32、AIが読んだ件数は24〜50で、小さい
- **美容室は本文のない口コミが34%**（星だけで書く人が多い）。読める件数が少なくなる
- **整骨院の「型」は24件が母数**で、1件が約4%。数字のゆれが大きい
- `chiropractor` には、整体・マッサージ店も含まれる（整骨院だけではない）
- **規約・著作権・個人情報は未確認。** 口コミの引用は言い換えにとどめ、投稿者名・スタッフ名は出していない
- **需要は未確認**

## 判断
- **「業種をまたいだ比較」は成立した**。設定だけで3業種が動き、共通点（応対）と固有の不満が分かれた
- **次の一手は、AIによる全件分類の自動化**。これができると、型の件数が安定し、「業種×街の口コミ調査」が、**キー1つで毎回同じ品質**で作れる（Claude APIのキーの登録が必要）
- 特定業種の口コミ通信（定期配信）にする場合も、**分類の精度が土台**になる
