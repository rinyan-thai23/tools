# 013 士業向け「探されている言葉」の地図（税理士の例）

- 日付：2026-11-26　／　実費：**$0.096**（1回目は取り出しを間違えて保存できず、取り直した。ミスで$0.048を損した）　／　状態：試験完了。**保留（設計の見直しが必要）**
- 区分：A（DataForSEOだけで完結）
- 一言：士業（税理士・司法書士など）の見込み客が、ネットで探している言葉を、月間検索数つきで並べる。

## 誰の、どんな悩みか
税理士・社労士・司法書士など、相談を受ける士業。お客さんがどんな言葉で困っているか分からず、HPや記事の題材が決められない。

## 強引チェック
1. 悩みは本当にあるか：**仮説**（士業に聞いていない）
2. APIなしで価値は成り立つか：言葉の探され方のデータがないと成り立たない。**APIが本体に近い**
3. 既存より何が良いか：**キーワード調査ツールは無料・安価なものが多い**（未調査）。差が出にくい
- **強引度：中〜高**（試した結果、上がった）

## 何をどのようにしたか
1. `dataforseo_labs/google/keyword_ideas/live` に、税理士のお客さんが探しそうな5つの種（税理士 相談／相続税 申告／個人事業主 確定申告／法人化 タイミング／インボイス 登録）を渡し、月間検索数50以上の300語を、検索数の多い順に取得（`tool/keyword_map.mjs`）
2. 関連語だけに絞り、表記ゆれ（空白・全角）をそろえて、グループごとに合計（`tool/cluster.mjs`・費用0）

## 使ったAPI・料金（実測）
`keyword_ideas/live`：**300語で$0.048**（1回$0.01 ＋ 1語あたり約$0.000127）。総数は152,207語ある

## 分かったこと（弱点が中心）
- **関連語は、取れた300語のうち約30%（90語）だけ。** 残りは「年金」（100万）「ガソリン税」「宝くじの税金」など、税理士と無関係な言葉。**検索数の多い順に取ると、一般的な言葉に埋もれる**
- **表記ゆれ・誤変換が多い**（「飼う低申告」が100万、「医療費 控除」と「医療費控除」が別語など）。そのまま渡すと数字が嘘になる
- **「法人化」の種を渡したのに、法人化の言葉が1語しか残らなかった。** 検索数の多い順で上位300語に切ると、種ごとの言葉が偏る
- **士業は地域の仕事。** 全国の言葉（「確定申告」100万）は、事務所の集客と直結しない。必要なのは「地域×相談内容」（例：「相続 税理士 ◯◯市」）で、これは今回の方法では取れていない
- **時期（確定申告の2〜3月など）の波は、この結果に入っていない**
- 「お客さんの悩みの言葉」には使えるが、**同じものは既存の無料ツールでも見られる可能性が高い**（未調査）

## 判断
- **保留。** 次に試すなら、`keyword_suggestions`（種を含む言葉だけ）＋地域名つきの言葉で取り、**関連語の判定と表記ゆれの統合を、AIで自動にする**。それでも、既存のキーワード調査ツールとの差は小さい
- 先に士業に**「何が分からなくて困っているか」を聞く**。「言葉の地図」が欲しいかは、仮説のまま
