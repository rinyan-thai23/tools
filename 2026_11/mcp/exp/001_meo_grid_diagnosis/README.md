# 001 場所ごとの順位マップ診断（店主向け）

- 日付：2026-11-26　／　実費：**$0.052**（試し1回＋25地点）　／　状態：LPの見本まで完了
- 一言：Googleマップの順位は、検索する場所で変わる。お店のまわりを格子で区切り、場所ごとの順位を1枚の地図にする。

## 誰の、どんな悩みか
飲食店・美容室・クリニックのオーナー。「うちの店、隣の駅から探している人に見えているのか？」が分からない。
喜ばれる理由：言葉で説明されるより、色のついた地図1枚のほうが一目で分かる。

## 何をどのようにしたか
1. **候補を考える**：MEO（マップ検索対策）で事業になりそうな形を7つ挙げ、「場所ごとの順位マップ」を武器に決めた
2. **1点だけ試す**（`data/probe_center_raw.json`）：高円寺駅(35.7057, 139.6497)で「ラーメン」。`serp/google/maps/live/advanced`。応答の形・料金($0.002)・時間(約3秒)を確認
3. **25地点を取る**（`data/grid_raw.json`）：駅を中心に 5×5。間隔は緯度0.005°（約550m）、経度0.0062°。公式MCPの `api_request` を5並列で呼んだ（`data/grid_first_version.mjs`。現在は `lib/grid.mjs` に一般化）
4. **「A店」を選ぶ**：結果158店のうち、多くの地点に出て順位の差が大きい店から、図がきれいな1店を選んだ（店名は伏せる）
5. **比較を作る**：どこかの地点で3位以内に入った店（上位店）の、口コミ数・写真数・星の中央値と並べた
6. **LPを作る**（`lp/index.html`）：店主向け。悩み→実例の地図→上位店との差→次の一手1つ→3ステップ→FAQ。実データ＋伏せ字。「見本です」と明記

## 使ったAPI
| 内容 | エンドポイント | 回数 | 費用 |
|---|---|---|---|
| マップ検索 | `/v3/serp/google/maps/live/advanced`（depth=20） | 1＋25 | $0.002/回（合計$0.052） |

## 結果（サンプル：高円寺・ラーメン・A店）
- A店は、店のすぐ近くでは1位。駅方面（北）へ離れると圏外が増える
- 上位店との差：口コミ 131件 対 350件、写真 326枚 対 807枚。星は 4.0 対 4.09 でほぼ同じ
- 次の一手：口コミをお願いする紙（QRコード）を置く

## 気づき・弱点
- 1地点で取れるのは上位20店。「圏外」は21位以下の意味
- 駅前の激戦区は、どの店も圏外が多くなる。商店街の小さな街のほうが図がきれい
- 「A店」はあとから選んだ店。実際の顧客の店ではない。**本当の店主に見せたときの反応は未確認**
- 順位は人・時間で変わる。LPにも「目安」と書いた
- 取るたびに少し結果が変わる（002で同じ条件を2回取ったら、上位店の星の平均が4.37→4.38）
