# 019 「全国から★4以上の●●の口コミを100〜1000件、無作為に抽出して」への対応力（見積り）

- 日付：2026-11-26　／　実費：**$0**（APIは叩いていない。公式の料金ページと、これまでの実測値だけで計算）　／　状態：見積り完了（未実行）
- 区分：**A（DataForSEOだけで完結）**
- 一言：「無茶な依頼」が来ても受けられるか。**技術と原価の面では、受けられる。** 難しいのは「無作為」の意味と、偏りの説明。

## 誰の、どんな悩みか（この見積りの立場）
依頼する側（調査会社・AI開発・業界メディア・コンサルなど）：「全国の、ある業種の、評価の高い店の口コミを、偏りなく、まとまった数が欲しい」。自分で集めるのは大変。
受ける側（私たち）の確認：**この依頼を、いくらで・どのくらいの時間で・どんな条件つきで受けられるか。**

## 結論（先に）
| 項目 | 判断 |
|---|---|
| 100〜1,000件を集める | **受けられる。原価は約5〜35円**（下の表） |
| 1万件 | 受けられる（約340円） |
| 10万件 | 受けられる。ただしリスト取得が33回に増え、**原価は約3,400円**（時間もかかる） |
| 「無作為」 | **完全な無作為はできない。** APIに無作為抽出の機能がない。**準無作為**（地域で層別＋ランダムな位置から取る）なら作れる。偏りは報告する |
| 本当の難所 | ①「★4以上」「無作為」「全国」の意味を決めること ②取得失敗のやり直し ③規約・個人情報の確認 |

**原価がほぼゼロなので、売値の根拠は「依頼の設計」と「偏りや欠損の品質報告」になる。**

## まず、依頼主に確認すること
1. **「●●」とは？** 業種（歯科、美容室…）か、特定のチェーン名か
2. **「★4つ以上」とは？** ①**店の平均評価が4.0以上**（店のフィルタで可能）か、②**口コミそのものが★4以上**（口コミは星で絞れず、取ってから選ぶ。★4以上は約83%なので、約1.2倍多く取れば足りる）か
3. **「無作為」とは？** 都道府県に均等に？ 店の数に比例して？ 1店あたりの上限は？
4. 期間（新しい順か）、本文なしの口コミの扱い（約9%が星のみ）、言語（日本語のみか）
5. **用途**：社内分析／AIの学習用／第三者への提供。**後ろ2つは、規約と著作権・個人情報の確認が必要**（未調査）
6. 納品形式（CSV／JSON）、**投稿者名・プロフィールURLを消すか**（取得データに入っている）
7. 予算と納期

## 作り方（案）
1. **店のリストを取る**：`business_data/business_listings/search/live`。業種（`categories`・最大10）、地域（`location_coordinate`：緯度,経度,半径km。最大100,000km＝全国を覆える）、`filters`（最大8個。例：`rating.value >= 4`）、`limit` 最大1,000／回
2. **無作為に近づける工夫**：地域（例：8地方、または47都道府県）ごとに分け、`offset` をランダムに選んで取る。必要な店数の**3倍**を取ってから、手元でランダムに間引く
3. **口コミを取る**：`business_data/google/reviews/task_post`＋`task_get`。`sort_by=newest` なら、Google側の「関連順」の偏りを避けられる。1店あたり10件程度にして、店の数を増やすと、偏りが減る
4. **失敗のやり直し**：0件で返ることがある（実測：11回中1回）。**料金は請求される**ので、10%の余裕を見る
5. **整える**：本文なしを除く、★4以上に絞る、投稿者名・URLを消す、重複を除く
6. **品質報告を付ける**：地域ごとの件数、本文なしの割合、偏りの注意

## 料金の計算（式と前提）
- **店のリスト取得**：1回 **$0.012 ＋ 1件 $0.00036**（公式の料金ページ。1,000件の1回で$0.372）
- **口コミ取得（標準キュー）**：**10件あたり $0.00075**（実測と一致。1Mで$75）。優先キューは2倍（$0.0015）で、約1分以内
- 前提：本文なしの割合9%（578件の実測）、1店10件、必要な店数の3倍をリストから取る、取得失敗の余裕10%、1ドル=150円

| 依頼（本文つき） | 取る口コミ | 店数 | リスト取得 | リスト費 | 口コミ費 | **合計** |
|---|---|---|---|---|---|---|
| 100件 | 110件 | 11店 | 33件／1回 | $0.024 | $0.008 | **$0.035（約5円）** |
| 1,000件 | 1,099件 | 110店 | 330件／1回 | $0.131 | $0.083 | **$0.235（約35円）** |
| 1万件 | 1万989件 | 1,099店 | 3,297件／4回 | $1.235 | $0.824 | **$2.27（約340円）** |
| 10万件 | 10万9,890件 | 1万990店 | 3万2,970件／33回 | $12.27 | $8.24 | **$22.6（約3,400円）** |
| （参考）1,000件を22店×50件で | 1,099件 | 22店 | 66件／1回 | $0.036 | $0.083 | $0.13（約20円） |
- 「少ない店から多く取る」ほうが安いが、**店の偏りが増える**（準無作為の質が下がる）。品質と原価のトレードオフ

## 時間
- 公式の標準キューは「最大45分」。**実測では、1店100件が数秒〜十数秒**だった
- 目安：100件は数分、1,000件は数分〜十数分、1万件以上は並列にして数十分〜（同時実行の上限は未確認。店のリスト取得は「同時30」まで）

## AIで「読む」場合の追加コスト（読むのが依頼に含まれるとき）
- 口コミの平均は**169文字**（本文あり）。1,000件（本文つき）で約17万文字、**日本語で約11〜17万トークン**（概算）
- 金額は、Claudeの料金表で計算が必要（このセッションでは未計算）。**データ取得よりAIの読み取りのほうが高くなる可能性が高い**
- 「抽出して渡すだけ」なら、AIは不要。この見積りは取得のみ

## 偏りと限界
- **APIに無作為抽出がない。** 地域別＋ランダムな位置の「準無作為」止まり
- **Googleマップに載る店だけ**（載っていない店は対象外）
- **評価4.0以上で絞ると、「評価の高い店だけ」という偏りが入る**（依頼の条件どおりだが、結論の解釈に注意）
- 日本語の業種名と、DataForSEOのカテゴリ名の対応は**未確認**（カテゴリ一覧の取得は別途確認が必要）
- 日本の店のリストの網羅率は**未確認**
- 口コミは、投稿者名・URLつきで返る。**納品物では消す**
- 口コミの二次利用（再配布・AI学習）の可否は、**DataForSEOとGoogleの規約・著作権を確認していない**。必ず確認する
