這個工具的優點

  • 回答以文字呈現。自家或競爭對手的名稱有沒有被提到，一眼就能確認。
  • 每次約 $0.002、約 4 秒。$1 約可查 450 次，可以換很多種問法來試。
  • 問題內容不受限。用潛在客戶可能的說法直接提問。
  • 可存成 CSV。回答內容可連同日期一起留存。
  • 標題與條列格式也能照樣閱讀。

不適合的情境

  • 需要最新資訊或引用來源 → 本工具不使用網路搜尋，只憑 Claude 既有的知識回答，也不會顯示引用來源（含網路搜尋的版本實測約 $0.025）。
  • 想要跟實際 Claude 畫面相同的回答 → 這是透過 API 詢問 claude-haiku-4-5 的結果，模型與回答可能和畫面不同。
  • 想自動判斷自家是否被提到 → 本工具只是把回答原樣列出。
  • 想長期追蹤 → 每次結果只是當下的一次回答。

本工具只專注一件事：看 Claude 在不使用網路搜尋時，如何回答某個問題。

常見問題

為什麼沒有引用來源？

因為不使用網路搜尋。如果需要引用來源，建議改用 Perplexity 或 Gemini 的工具。

費用會隨回答長度而變動嗎？

實測約 $0.002（兩次分別為 $0.0022、$0.0024）。回答很長時的費用尚未測量。

為什麼沒有選擇國家與語言的欄位？

因為這個呼叫沒有國家或語言的參數。

同一個問題，回答會一樣嗎？

每次的回答可能不同。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
