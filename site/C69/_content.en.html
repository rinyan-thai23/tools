Why use this tool

  • A profile in a table from one line. "一蘭 新宿中央東口店" showed a 4.3 rating, 7,891 reviews and 11,947 photos (measured).
  • Opening hours by weekday. A second table lists Monday through Sunday.
  • About $0.0054 per call. Roughly 185 per $1, so you can check nearby shops in a row.
  • Returned in Japanese. Category and address came back in Japanese (measured).
  • Save as CSV. A draft for a comparison sheet with other shops.

When it is not the right fit

  • You want to edit the profile → this tool only looks. Editing is done in the Google Business Profile dashboard.
  • You are not sure it found the right shop → we tested only one shop, but if the name and area do not match, a different shop may come up. Check the name in the first row.
  • You want the text of customer reviews → the table has only the number of reviews.
  • Blank opening hours → a blank weekday means either a day off or no data. This tool cannot tell which.

This tool does one thing: show one shop's Google Business info (name, category, rating, review count, address, phone, photo count and opening hours).

FAQ

How do I write the shop name and area?

Join them with a space on one line, like "一蘭 新宿中央東口店".

What does "00:00–24:00" in the hours mean?

Open 24 hours. Every weekday was like that for the shop we tried.

How many shops did you test?

One (一蘭 新宿中央東口店). We have not checked other shops or shops with little data.

Can I look up other shops?

The tool is built to look up whichever shop you enter. We tested only one, so check the name in the first row if a different shop comes up.
