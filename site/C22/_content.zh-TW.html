這個工具的優點

  • 取得接近畫面的內容。回答內文、引用來源與推薦商品並列呈現。
  • 每次約 $0.004。$1 約可查 250 次，換關鍵字反覆確認也沒負擔。
  • 看得到商品名稱與標籤。像「平價高 CP 值」「中價位首選」「iPhone 首選」這類標籤，能看出商品是如何被介紹的（台灣範例的商品有 5 項、引用來源有 3 筆）。
  • 可選國家與語言。能以指定地區的結果來看。
  • 可存成 CSV。引用來源表可以留存。

不適合的情境

  • 想立刻拿到結果 → 需要約 20～30 秒（實測 21～31 秒），因為是先搜尋、再產生回答的流程。
  • 想要商品價格或網址 → 商品表只顯示名稱、標籤與圖片。價格與網址在範例中幾乎是空白。另外，台灣範例的商品圖片與來源頁面，有些來自海外商店（例如 Shopee 新加坡、Anker 日本官網），未必是台灣的販售頁面。
  • 想自動判斷自家商品是否出現 → 本工具只是把取得的結果列出。
  • 想長期追蹤 → 每次結果只是當下的一次回答。

本工具只專注一件事：看某個關鍵字在 ChatGPT 搜尋中如何回答、引用了什麼、推出哪些商品。

常見問題

為什麼要花 20～30 秒這麼久？

因為是先搜尋、再產生回答的處理流程。實測約 21～31 秒（台灣範例約 21 秒、日本範例約 31 秒）。

這是哪個模型的結果？

API 回傳的模型顯示為 gpt-6。結果未必與 ChatGPT 畫面完全相同。

和「查看 ChatGPT 的回答」有什麼不同？

那個工具是透過 API 直接詢問 ChatGPT 的模型；這個工具則是取得 ChatGPT 搜尋畫面上的形式（包含引用來源與商品）。

商品圖片可以直接使用嗎？

圖片是 ChatGPT 回傳的內容。他人的圖片具有著作權，請僅作為參考查看。

選擇國家與語言，會有什麼不同？

結果會是以該國家、語言執行 ChatGPT 搜尋所得到的內容。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
