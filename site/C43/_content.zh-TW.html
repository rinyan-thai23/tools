如何查熱門搜尋詞？主要工具比較

在構思電子書或部落格主題時，會想先看看大家到底最常搜尋什麼。不需要輸入任何東西，按下按鈕，就會依搜尋量由高到低，把關鍵字與每月搜尋量整理成 100 筆的表格。

本工具的優點

  • 不需要輸入。完全沒頭緒的時候，可以當作起點。
  • 看得出搜尋量的量級。第 1 名日文的「天気」（天氣），每月搜尋量為 6,800 萬（實測，日本）。
  • 每次約 $0.024。$1 約可查 40 次。
  • 約 2 秒回傳。
  • 可存成 CSV。

不適合的情境

  • 想知道現在的話題詞 → 這不是「時事熱門」榜單。排在上面的，是長期搜尋量很高的詞（例如「天気」「youtube」）。
  • 想找值得寫的主題 → 像「天気」「youtube」這種詞，對文章主題來說太廣了，榜上這類詞很多。
  • 被拼錯的詞干擾 → 「yo0utube」「youtub3」「ytb」這類輸入錯誤的詞也會排在前面（實測）。本工具不做篩選。
  • 需要超過 100 個詞 → 上限為 100 個詞（總數為 3.4 億個詞）。

本工具只專注在一件事：原樣呈現搜尋量最高的前 100 個詞。

常見問題

每次出現的詞都一樣嗎？

因為是依搜尋量由高到低的前段名單，不會有太大變化。範例中也是「天気」排在第一。

為什麼會有「yo0utube」這種詞？

因為本工具原樣呈現 API 回傳的值，原因本工具無從得知，也沒有做篩選。

國家與語言會影響什麼？

它決定查詢數據的市場。選擇日本、日文，就會是日本搜尋量的前段名單。

為什麼沒有輸入欄？

因為這個 API 不接受指定詞彙，只依國家與語言運作。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見What is DataForSEO?（英文）。
