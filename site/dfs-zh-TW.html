什麼是 DataForSEO？

一句話說明

這是一項讓你透過 API 取得「SEO 資料」的服務，包括搜尋結果、廣告、關鍵字等。可以把它想成許多 SEO 工具背後的資料供應商。

本站的工具把 DataForSEO 的功能做成畫面，一個工具只做一項功能，並把回傳的資料直接整理成表格呈現。

可以做什麼？

  • 搜尋結果（SERP）：Google 搜尋、地圖、新聞、圖片等的排名與內容
  • 關鍵字：搜尋量、相關關鍵字等
  • 網站分析：反向連結、網站使用的技術等
  • 商家資料：店家與公司的評價、基本資料

每個工具頁面都會說明它的用途。請從工具列表選擇。

計費方式

  • 用多少付多少。沒有固定月費。
  • 先儲值餘額，每次查詢會從中扣款。
  • 每個工具頁面會標示每次查詢的大約費用，執行後畫面會顯示實際費用。
  • 最新的儲值條件，請以 DataForSEO 官方網站為準。

註冊前請注意

無法使用免費信箱（Gmail、Yahoo 信箱等）註冊。
請使用公司信箱或自己網域的信箱。
  • 在工具中需要輸入兩項資料：登入信箱與 API 密碼。
  • API 密碼在後台的「API Access」頁面，與登入密碼不同。
  • 金鑰只會儲存在你的瀏覽器中，不會傳送到本站的伺服器。

開始使用

  1. 建立 DataForSEO 帳號
  2. 在後台的「API Access」找到 API 密碼
  3. 在首頁輸入信箱與 API 密碼並儲存
  4. 打開任一工具，先看範例，再實際查詢
