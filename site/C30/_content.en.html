Why use this tool

  • About $0.0012 per call. About 800 per $1, so you can test genre ideas freely.
  • Weekly numbers in a table. Check the ups and downs in numbers.
  • About 4 seconds.
  • Pick a country. See numbers for Japan and others.
  • Save as CSV.

When it is not the right fit

  • You want the same numbers as Google Trends → this is the popularity DataForSEO returns. It may not match Google Trends (we have not compared).
  • You want search counts → popularity is relative, with the period's peak set to 100.
  • You want to compare several keywords → this tool takes one. "See Google Trends over time" fits better.
  • There is no language setting.

This tool does one thing: fetch the weekly popularity trend of one keyword.

FAQ

How is it different from Google Trends?

Google Trends is Google's own screen and data. This tool shows the popularity DataForSEO's API returns; we have not checked that the numbers match.

Why can I not choose a language?

This API does not accept a language setting, only a country.

Is the price really $0.0012?

We measured $0.0012.

How many weeks are shown?

52 weeks in our sample.

Can I sign up with a free email address?

No. DataForSEO does not accept free email providers. See What is DataForSEO?
