如何查看各地區的搜尋熱度，以及常見工具比較

在店面所在的區域投放廣告或發傳單之前，會想知道這個字詞在哪些地區最常被搜尋。輸入一個關鍵字，就會把各地區的熱度列成表格（日本版以都道府縣為單位）。

本工具（DataForSEO）每次呼叫計費。每次約 $0.0024（實測）一個關鍵字的地區別熱度表。可存成 CSV。地名以英文回傳

此工具的優點

  • 各地區的數字整理成表格。可以排序，找出熱度高的地區。
  • 約 $0.0024。$1 約可查 400 次。
  • 約 1 秒回應。實測約 1 秒。
  • 可選擇國家。
  • 可存成 CSV。

不適合的情境

  • 想看中文地名：地名是 API 回傳的英文（例如日本的 Aichi、Akita），本工具不做中文轉換。
  • 想知道搜尋次數：熱度是以最高值為 100 的相對值。
  • 想看到鄉鎮市區：本工具回傳的是第一層行政區（日本實測為 42 個地區）。
  • 不見得每個行政區都有資料（範例只有 42 個地區）。
  • 想知道廣告成效：熱度只是搜尋多寡的參考，看不出廣告成果。
  • 實測結果：「副業」回傳 42 個地區，「ラーメン」回傳 46 個地區（日本關鍵字）。

本工具專注在一件事：取得「關鍵字的各地區熱度」。它用來看地區間的偏重，並不是用來比較各地的搜尋次數。

常見問題

為什麼地名是英文？

因為 API 以英文回傳，這裡照原樣顯示。

數字的「100」是什麼？

是熱度最高的地區設為 100 的相對值，不是搜尋次數。

日本的 47 個都道府縣會全部出現嗎？

範例只有 42 個地區。只會顯示 API 回傳的資料列。

換成其他國家會怎麼樣？

會變成該國各地區（例如州）的熱度。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
