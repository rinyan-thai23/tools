When it is not the right fit

  • You want Japanese place names → names come as the API returns them in English (Aichi, Akita and so on). We do not convert them.
  • You want search counts → popularity is relative, with the top region set to 100.
  • You want cities or wards → the table is by prefecture (42 regions in our test).
  • You may not get all 47 prefectures (our sample had 42).
  • You want to know how well ads would work → popularity is a guide to search interest, not ad results.
  • We saw 42 regions for "副業" and 46 for "ラーメン".

This tool does one thing: show a keyword's popularity by region.

FAQ

Why are place names in English?

The API returns them in English and we show them as they are.

What is the "100"?

The most popular region is set to 100. It is not a search count.

Do I get all 47 prefectures?

Our sample had 42 regions. We show only the rows the API returns.

What happens if I change the country?

You get popularity by that country's regions, such as states.
