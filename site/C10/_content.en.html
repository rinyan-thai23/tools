Why use this tool

  • Look up by shop name. Even a generic word like "ラーメン" returned three advertisers in our sample.
  • An ad-count estimate. A rough sense of how seriously an advertiser spends.
  • About $0.002 and 2–3 seconds. About 500 lookups per $1, so you can check several rivals in a row.
  • Filter by country. Choose Japan or another market.
  • Save as CSV. Advertiser IDs come along.

When it is not the right fit

  • You want to search by domain → this tool looks up a name. With a domain it returned only domain names, with no advertiser ID or count (checked with nike.com).
  • You want to see the ads → the table has advertiser info only. Use the "see running ads" tool or Google's Transparency Center.
  • You need an exact ad count → the number is the API's approximate value.
  • A large company may show many advertiser IDs in one row (we saw this with Uniqlo).

This tool does one thing: list the advertisers registered with Google under a name.

FAQ

What if the shop does not run ads?

You will see "No results found". That does not prove they run no ads; try another spelling.

Is the ad count the number of ads running now?

It is the API's approximate figure, shown as is. This tool cannot say whether it is current.

What is the advertiser ID for?

It is a key for finding that advertiser's ads in Google's Transparency Center.

Why does one company show several advertiser IDs?

Large companies can hold several advertiser accounts. In our Uniqlo lookup, one row listed several IDs.
