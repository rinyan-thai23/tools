如何查競爭對手的廣告主資料，以及常見工具比較

同業的店家或公司，到底有沒有投放 Google 廣告？想知道，卻又不能直接去問對方的業務。輸入公司名稱或店名後，本工具會把 Google 上登錄的廣告主名稱、廣告主 ID、國家與廣告數量的概略數字整理成表格。

方法・工具收費方式特色
本工具（DataForSEO）每次查詢按量計費，約 $0.002（實測）輸入公司名稱，以清單呈現廣告主名稱、廣告主 ID、國家與廣告數量的概略數字，可存成 CSV
Google 廣告透明度中心（手動）免費Google 官方提供。可用廣告主名稱或網站名稱搜尋，並依地區、期間篩選（官方說明）。也能直接看到廣告內容
Semrush Advertising Toolkit月費制（Base、Pro 兩種方案，費用請至官網確認）跨多個廣告平台調查競爭對手。功能廣泛，但對小型店家來說規模偏大
Ahrefs Site Explorer月費制（方案請至官網確認）可查看各網站的付費搜尋概況。用途是網站分析，不是廣告主清單

以上為 2026年11月時點的調查。費用可能調整，申請前請至各家官網確認。

本工具的優點

  • 用店名就能查。連「ラーメン」（拉麵）這樣的詞，也回傳了 3 筆廣告主（範例，日本關鍵字）。
  • 看得到廣告數量的概略數字。可以大致判斷對方投放得有多積極。
  • 約 $0.002、約 2 到 3 秒。$1 約可查 500 次，可以連續查好幾家附近的競爭對手。
  • 可選擇國家。在國家欄位選擇日本等國（無法細分到縣市等地區）。
  • 可存成 CSV。廣告主 ID 也可以一併記下來。

不適合的情境

  • 想用網域查詢 → 本工具是以公司名稱查詢。改用網域時，只會回傳網域名稱，沒有廣告主 ID 或廣告數量（以 nike.com 確認）。
  • 想看廣告內容 → 表格只顯示廣告主的資訊。要看廣告本身，適合改用其他工具（查看刊登中的廣告），或 Google 廣告透明度中心。
  • 需要精確的廣告數量 → 表格中的數字是 API 回傳的「概略數字」。
  • 大型企業的公司名稱可能對應多個廣告主 ID，因此會並列好幾個 ID（以日本品牌「ユニクロ」確認）。

本工具專注在一件事：列出「這個公司名稱，在 Google 上登錄了哪些廣告主」。

常見問題

沒有投放廣告的店家，結果會是什麼？

找不到廣告主時，會顯示「找不到結果」。這並不代表對方沒有投放。請換個名稱寫法再試試。

廣告數量是目前刊登中的廣告數嗎？

是照原樣顯示 API 回傳的「概略數字」。是否為目前的數量，本工具無法判斷。

廣告主 ID 有什麼用途？

在 Google 廣告透明度中心搜尋該廣告主的廣告時，可作為辨識的依據。

為什麼同一家公司會出現好幾個廣告主 ID？

大型公司可能擁有多個廣告主帳號。查詢「ユニクロ」時，就有多個 ID 並列在同一列。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見What is DataForSEO?（英文）。
