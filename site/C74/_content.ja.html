サイトの使用技術を調べる方法と、主なツールの比較

制作の仕事では、相手のサイトが、何で作られているのかを最初に知りたい。ドメインを入れると、そのサイトが使っている技術（サーバー、解析、広告など）を、分類ごとに表にします。

※ 改行で、たくさん入れられるようになりました（1件ずつ送るので、料金は件数ぶんかかります）。表には「入力」の列が付きます。下の説明の「1つ」は、1件だけ入れたときの内容です。料金の目安は、ページ上部の表を見てください。

このツールのメリット

  • 使っている技術が、一覧になる。xserver.ne.jpは、6行になりました。アフィリエイト（A8.net）、サーバー（Apache HTTP Server、Xserver）、解析（Google Analytics、Facebook Pixel）、タグ管理（Google Tag Manager）、JavaScript（jQuery）でした（実測）。
  • 1回 約$0.012。$1で約83回。
  • 約4秒。実測の時間です。
  • URLで入れても大丈夫。「https://www.xserver.ne.jp/」でも、ドメインに直して調べます。
  • CSVで保存できる。お客さんへの提案の下調べに使えます。

向いていない場面

  • 技術の使用の履歴が欲しい → これは、いまの時点の結果です。
  • 日本語の分類名が欲しい → 分類と種類は、英語の名前です（例：Web servers）。
  • アクセス数などの数値が欲しい → この表は、技術の名前だけです。
  • 見つからない技術がある → 調べられるのは、DataForSEOが見つけた技術だけです。

このツールは、「1つのドメインの、使用技術（分類・種類・技術名）」を見ることに絞っています。

よくある質問

分類や種類は、何ですか？

DataForSEOの分類です。たとえば「Servers」の中の「Web servers」「Hosting」のように、2段で分かれます。

wwwを付けるか、迷います。

付けても付けなくても大丈夫です。このツールが、ドメインの形に直して調べます。

料金は、技術の数で変わりますか？

1ドメインあたり約$0.012でした。試した1ドメインでは、技術の数による違いは見ていません。

ページ1つの技術ではないのですか？

ドメインごとの結果です。ページごとには出ません。

フリーメールで登録できますか？

DataForSEOは、フリーメールでは登録できません。くわしくはDataForSEOとは？をご覧ください。
