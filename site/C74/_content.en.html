Why use this tool

  • The technologies in one list. xserver.ne.jp came out as six rows: affiliate (A8.net), servers (Apache HTTP Server, Xserver), analytics (Google Analytics, Facebook Pixel), tag management (Google Tag Manager) and JavaScript (jQuery) (measured).
  • About $0.012 per call. Roughly 83 per $1.
  • About 4 seconds. That is what we measured.
  • Paste a URL if you like. "https://www.xserver.ne.jp/" is converted to the domain before the lookup.
  • Save as CSV. Groundwork for a proposal to the client.

When it is not the right fit

  • You want a history of technology use → this is a snapshot of now.
  • You want Japanese category names → categories and types are English names (e.g. Web servers).
  • You want figures such as traffic → the table has technology names only.
  • You are missing a technology you expected → only technologies DataForSEO detected are listed.

This tool does one thing: show one domain's technologies (category, type and name).

FAQ

What are the categories and types?

DataForSEO's classification, in two levels: for example "Web servers" and "Hosting" under "Servers".

Should I add www?

Either way works. The tool converts what you type into the plain domain.

Does the price change with the number of technologies?

It was about $0.012 for the one domain we tried. We did not look at how the number of technologies matters.

Is this per page?

No. It is a result per domain, not per page.

Can I sign up with a free email address?

No. DataForSEO does not accept free email providers. See What is DataForSEO?
