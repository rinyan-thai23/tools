Why use this tool

  • Comment text in a table. Save as CSV and search a spreadsheet for words like "broke" or "never arrived".
  • Likes and replies attached. See which comments struck a chord.
  • A few seconds. About 6–7 seconds for 20 comments and about 7 for 100 (measured).
  • About $0.01 for 100. Read a hundred comments from one video in one go.
  • Dated. Tell old comments from recent ones.

When it is not the right fit

  • You want every comment → up to 100 per call. A video with millions of comments still returns only the number you choose.
  • You want to know which comments are honest → the tool just lays the comments out.
  • You need a specific order → comments come in the order the API returns, not necessarily by likes.
  • You want reply text → the reply count is shown, not the replies.
  • You can write code → the official YouTube Data API costs 1 unit per comment request; use it for large volumes.

This tool does one thing: lay out one video's comments and their numbers.

FAQ

Can I fetch more than 100?

This version offers 20, 50 or 100.

Why is the date not shown like "7 years ago"?

We use the timestamp and show a date.

May I reuse other people's comments?

Comments belong to their authors. This table is for reading trends; respect the rights of the author and the video owner if you quote.

Why is there no country or language selector?

The lookup is by video ID. We fix it to Japan and Japanese.

Can I sign up with a free email address?

No. DataForSEO does not accept free email providers. See What is DataForSEO?
