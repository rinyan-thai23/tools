Why use this tool

  • The answer and its links, side by side. See which pages the answer links to, with URLs.
  • Ask the question as a customer would. Type it in their words.
  • About $0.03 and a few seconds. Our New York sample took 4.1 seconds and cost $0.027. About 37 per $1, so you can try questions casually.
  • Answers with web search. The answer uses search results, not only stored knowledge.
  • Save as CSV. Keep the cited pages by date.

When it is not the right fit

  • You want exactly what the ChatGPT screen shows → this tool asks gpt-4o-mini through the API. The model and the answer can differ from the app. For the screen itself, use the "see ChatGPT search" tool.
  • You want a verdict on whether your shop appeared → the tool just lays out the answer.
  • You want daily tracking → one call is one answer at one moment, and the same question can come back a little different each time.
  • You want the answer for a customer in a specific place → you cannot set a location.
  • The links are not always the reference sites → in our New York sample all three links pointed to Google Maps search pages. The table shows the links inside the answer.

This tool does one thing: show how web-search ChatGPT answers a question and what it cites.

FAQ

Why does one call cost about $0.03?

Web search adds input to the request. In our tests a cheap model without web search cost about $0.002, while gpt-4o-mini with web search cost about $0.027.

Can the sources table be empty?

Yes, if the answer includes no citations.

Why is there no country or language selector?

This API call has no country or language setting. Write the question in the language you want the answer in.

Will the same question give the same answer?

Answers can change from call to call. To see the difference, fetch again on another day.

Can I sign up with a free email address?

No. DataForSEO does not accept free email providers. See What is DataForSEO?
