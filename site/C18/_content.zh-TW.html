如何查 ChatGPT 的回答？主要工具比較

當顧客問 ChatGPT「台北信義區有哪些推薦的拉麵店？」，你的店會不會被提到？回答裡又附了哪些連結？輸入問題後，這個工具會把 ChatGPT（含網路搜尋）的回答，以及回答中引用的頁面清單整理成表格。

這個工具的優點

  • 回答與引用來源並列。回答中連結的頁面，連同網址一起看得到。
  • 問題可以自由輸入。用顧客可能的問法直接試。
  • 每次約 $0.03、約 4～8 秒。實測台灣範例 6.5 秒、日本範例 4.5 秒。$1 約可查 37 次，換個問法試試也沒負擔。
  • 含網路搜尋的回答。不是只靠舊知識作答，而是參考搜尋結果後的回答。
  • 可存成 CSV。每天的引用頁面清單都能留存。

不適合的情境

  • 想要跟實際 ChatGPT 畫面完全相同的回答 → 本工具是透過 API 詢問 gpt-4o-mini 的結果，模型與回答可能和畫面不同。若想看畫面本身，請用「查看 ChatGPT 搜尋畫面」。
  • 想自動判斷自家店是否出現 → 本工具只是把回答原樣列出。
  • 想每天追蹤 → 每次結果只是當下的一次回答，同樣的問題，回答每次也可能略有不同。
  • 想看顧客所在位置（附近店家）的回答 → 無法指定地點。
  • 引用的連結未必是資料來源網站 → 範例中的連結是 Google 地圖的搜尋頁面。表格列出的是回答中的連結。

本工具只專注一件事：看含網路搜尋的 ChatGPT 對某個問題怎麼回答、引用了什麼。

常見問題

為什麼一次要約 $0.03？

含網路搜尋時，搜尋內容會增加輸入量。實測不含網路搜尋的低價模型約 $0.002，gpt-4o-mini 含網路搜尋約 $0.027。

引用來源的表格會是空的嗎？

如果回答沒有附引用，表格就會是空的。

為什麼沒有選擇國家與語言的欄位？

因為這個 API 呼叫沒有國家或語言的參數。只要用繁體中文提問，就會以中文回答。

同一個問題再問一次，回答會一樣嗎？

每次的回答可能不同。想比較差異時，請隔幾天重新取得。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
