如何查搜尋意圖？主要工具比較

寫聯盟行銷文章時，搜尋這個關鍵字的人，是準備要買，還是只是在查資料，會決定文章該怎麼寫。把關鍵字一行一個貼進來，就會把每個詞的搜尋意圖整理成每個詞各列一列的表格。

本工具的優點

  • 多個關鍵字的意圖一次看。可以把文章候選詞分成「想買的人」和「想查資料的人」兩類。
  • 意圖名稱是中文。分成「查詢資訊」「比較、評估」「購買、申請」「前往特定網站」四種。
  • 3 個詞約 $0.012。
  • 幾秒內回傳。台灣範例實測不到 1 秒。
  • 可存成 CSV。

不適合的情境

  • 想用數字知道意圖的把握程度 → API 其實也會回傳機率，但本工具的表格不顯示。
  • 混合多種意圖的詞 → 表格只會顯示最強的那一種意圖。例如日文的「ブログ 始め方」，查詢資訊的意圖約 62%，前往特定網站的意圖約 37%（日本關鍵字的實測）。台灣範例中，「咖啡 推薦」為比較、評估（約 80%），「旅遊 行程」為查詢資訊（約 97%），「聯盟行銷 是什麼」為查詢資訊（近 100%），3 個詞都只有單一主要意圖。
  • 期待和其他工具的判定相同 → 名稱和 Semrush 的四種相近，但判定方式是各工具自己的，同一個關鍵字的結果可能不同。
  • 不能選擇國家，只能選擇語言（因為 API 只接受語言）。

本工具只專注在一件事：用中文名稱，一次查看多個關鍵字的搜尋意圖。

常見問題

四種意圖分別代表什麼？

查詢資訊（想知道）、比較、評估（買之前想先比較）、購買、申請（想採取行動）、前往特定網站（正在找那個網站）。

「比較、評估」等於想購買嗎？

不等於。這是購買前的調查階段。想購買的意圖是「購買、申請」。

為什麼不顯示機率？

本工具只把 API 回傳的意圖名稱整理成表格。

最多可以輸入幾個詞？

依 DataForSEO 的規格，最多 1000 個詞。本工具實際確認過的是 3 個詞。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
