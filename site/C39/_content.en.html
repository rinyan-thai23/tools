Why use this tool

  • Check the intent of many keywords together. Sort article ideas into buyers and researchers.
  • Four intent names. Informational, Commercial, Transactional and Navigational (shown in the page language).
  • About $0.012 for 3 keywords and $0.072 for 500 (measured). Up to 1,000 go in one request; more are split automatically (up to 5,000).
  • A few seconds. We measured under 1 second for the call.
  • Save as CSV.

When it is not the right fit

  • You want how sure the intent is → the API returns a probability, but this table does not show it.
  • You have keywords with mixed intent → only the strongest intent is shown. For example, "wireless earbuds cheap" came back as commercial at about 72% probability (measured in the US).
  • You assume the same verdict as other tools → the four names match Semrush's, but each tool makes its own judgement, so the same keyword can come out differently.
  • You cannot choose a country, only a language (the API accepts a language only).

This tool does one thing: show the search intent of several keywords with plain names.

FAQ

What do the four intents mean?

Informational (wants to know), Commercial (comparing before buying), Transactional (wants to act) and Navigational (looking for a specific site).

Is "Commercial" the same as buying?

No. It is the research stage before buying. Buying is "Transactional".

Why is the probability not shown?

The tool tabulates only the intent name the API returns.

How many keywords can I enter?

DataForSEO's spec says up to 1000. We confirmed up to 3 here.
