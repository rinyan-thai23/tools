Why use this tool

  • The top results in a table. Views, date and length at a glance show what length dominates.
  • About $0.002 for 20 results. About 500 per $1, so you can test several genre ideas.
  • About 5 seconds. 5 seconds for 20 results, about 11 for 100 in our test.
  • Pick a country and language. See results as seen from Japan.
  • Save as CSV. Keep a list of videos to study.

When it is not the right fit

  • You want the same order as your own recommendations → this tool returns search results.
  • You want playlists and other non-video blocks → only videos are shown. One of 20 items was a playlist in our sample, so the table can have fewer rows than you asked for.
  • You want to track a channel's growth → each call gives one snapshot, not a trend.
  • Some videos have no view count (1 of 20 in our sample). Missing values stay blank.

This tool does one thing: show what leads YouTube search for a keyword, as many as you ask for.

FAQ

How does the cost change with the count?

In our test: $0.002 for 20, $0.006 for 50 and $0.01 for 100.

Why does the table have fewer rows than the count I chose?

Non-video blocks such as playlists are removed.

Is the upload date not shown like "1 year ago"?

The API returns both a text like that and a timestamp. We use the timestamp and show a date.

Is the ranking always the same?

YouTube results change over time, so each fetch can differ a little.
