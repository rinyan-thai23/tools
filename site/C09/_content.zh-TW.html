本工具的優點

  • 搜尋結果可以用表格帶走。名稱、提供者、更新日與連結並排，適合在比較候選資料前先做功課。
  • 20 筆約 $0.002。$1 約可查 500 次，可以一邊換主題一邊反覆搜尋。
  • 數秒就有結果。實測約 2 到 3 秒。
  • 看得到更新日。可作為避免選到過時資料的參考（也有空白的列）。
  • 可存成 CSV。候選資料的出處連結，可以一併保存。

不適合的情境

  • 想直接看資料內容 → 表格只顯示名稱、提供者、更新日與連結，數字要到連結的提供者頁面確認。
  • 只想找特定國家的官方統計 → 直接到該國的政府統計入口比較精準。範例中的「population japan」，排在前面的是民間網站的彙整頁面。
  • 想確認使用條件 → 本工具的表格不會顯示。使用前請先到連結頁面閱讀使用條件。
  • 想用中文關鍵字查 → 實測使用的是英文，中文尚未驗證。

本工具專注在一件事：取得「某個主題的公開資料集，刊載在哪些地方」的清單。

常見問題

表格裡的資料，可以直接放進文章或書裡嗎？

每份資料的使用條件都不同，本工具不判斷能否刊載。請到連結的提供者頁面，確認使用條件與出處標示方式。

為什麼有些列的更新日或提供者是空白？

因為是照原樣顯示 API 回傳的值。實測（20 筆）中，提供者空白的有 4 筆，更新日空白的有 1 筆。

為什麼沒有選擇國家與語言的欄位？

因為這個 API 只需要關鍵字就能運作。

可以選擇筆數嗎？

本工具固定為 20 筆。若取 40 筆，費用約為 $0.004（實測）。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
