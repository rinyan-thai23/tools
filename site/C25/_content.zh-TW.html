接手客戶的網站之後，第一件事通常是先列出與這個網站相關的關鍵字候選。輸入網域，就能看到 Google 關聯到該網站的關鍵字，並附上月搜尋量、CPC 與競爭程度。

此工具的優點

  • 只要網域就能查。以「example.com」的格式輸入即可。
  • 單次可到 998 列。實測 rakuten.co.jp 回傳 998 列，$0.09 就能取得約 1000 列以內的資料。
  • 附月搜尋量、CPC、競爭程度。可用來替候選詞排優先順序。
  • 幾秒內回應。實測約 5～8 秒。
  • 可存成 CSV。再用試算表篩選即可。

不適合的情境

  • 想知道網站實際的排名：這裡列的是 Google 關聯到網站的廣告用關鍵字候選，並不是網站的排名。
  • 列數太多：結果會全部列出，畫面會很長，建議存成 CSV 後用試算表篩選。
  • 競爭程度的意思：表中的是 Google Ads 的競爭程度（0～100），不是 SEO 的難度。
  • CPC 有空白列：rakuten.co.jp 的 998 列中有 140 列是空的（實測，範例僅顯示前 30 列），會照實顯示為空白。
  • 公司名稱、商品名稱等品牌字也會混在其中。
  • 有些網域回傳 0 列：suumo.jp 回傳 0 列，但仍然收費 $0.09（實測）。

本工具專注在一件事：把「與這個網域相關的關鍵字候選」連同搜尋量列成一張表。

常見問題

這些關鍵字是網站已經有排名的字嗎？

不是。這是 Google Ads 的關鍵字候選，不代表網站的排名。

為什麼會回傳將近 1000 列？

因為 API 回傳的資料會原封不動全部顯示，筆數無法自行選擇。

為什麼日文和英文會混在一起？

與網站相關的字詞會照原樣列出，所以也會看到像「rakuten jp」這類英文列。

CPC 空白代表什麼？

代表 API 沒有回傳數值，這裡照實顯示為空白。

結果是 0 列也要收費嗎？

要。suumo.jp 回傳 0 列，仍然收費 $0.09（實測）。

台灣的網站查得到嗎？

可以。國家選「台灣」、語言選「繁體中文」即可（語言代碼由工具在內部自動對應）。範例以 momoshop.com.tw 查詢，回傳了 469 列。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
