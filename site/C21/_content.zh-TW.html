如何查 Perplexity 引用了哪些網站？主要工具比較

如果你在寫聯盟行銷文章，會很想知道：Perplexity 在這個主題上，引用的是哪些網站？輸入問題後，這個工具會把 Perplexity（sonar）的回答，以及引用的搜尋結果（標題、網址）整理成表格。

方法／工具收費方式特色
本工具（DataForSEO）按次計費。每次約 $0.006（實測）輸入問題，顯示回答內文與引用的搜尋結果（標題、網址）。可存成 CSV。模型固定為 sonar
Perplexity 畫面（手動）有免費方案，付費方案價格請至官網確認自己提問、自己閱讀。看到的就是實際畫面。紀錄要自己留存

這個工具的優點

  • 搜尋結果列出 10 筆。範例回傳了 10 筆，標題與網址都可以留存。
  • 每次約 $0.006、約 3～5 秒。實測台灣範例約 3.6 秒、日本範例約 3.4 秒。$1 約可查 170 次，換主題反覆試也沒負擔。
  • 掌握回答依據的線索。可以比較被引用的是哪些類型的媒體。
  • 可以自由輸入問題。
  • 可存成 CSV。

不適合的情境

  • 想要跟實際 Perplexity 畫面相同的結果 → 這是 API 的 sonar 模型的回答，可能與畫面上的 Pro 搜尋等不同。
  • 想判斷引用來源是如何被使用的 → 本工具只是把搜尋結果列出。
  • 想長期追蹤 → 每次結果只是當下的一次回答。
  • 想自選模型 → 本工具固定使用 sonar。

本工具只專注一件事：看 Perplexity 如何回答某個問題、引用了哪些頁面。

常見問題

引用來源的表格，和回答內文中的引用一樣嗎？

表格是 API 回傳的搜尋結果清單。回答內文中的編號引用與表格的對應，本工具並未處理。

為什麼沒有指定網路搜尋的選項？

sonar 是會附帶搜尋結果的模型（範例與實測都有回傳搜尋結果），因此本工具沒有另設指定欄位。

為什麼沒有選擇國家與語言的欄位？

因為這個呼叫沒有國家或語言的參數。

費用會隨回答長度而變動嗎？

實測約 $0.006（台灣範例 $0.005955、日本範例 $0.005928）。回答很長時的費用尚未測量。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
