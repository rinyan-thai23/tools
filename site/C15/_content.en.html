Why use this tool

  • Just paste the URL. A video URL or a video ID both work.
  • The description comes along. Keep the title and description next to the numbers.
  • About $0.006. About 160 lookups per $1, so you can log many videos.
  • About 7 seconds. That is what we measured.
  • Save as CSV. Fetch again later and compare the numbers yourself.

When it is not the right fit

  • You want a trend over time → each result is a snapshot.
  • You want numbers only the owner sees, such as revenue or audience age → they are not shown.
  • You want channel-wide numbers → this is one video per call.
  • You want many videos at once → one per call.

This tool does one thing: tabulate the public numbers of one video.

FAQ

Which URL forms work?

watch?v= links, short youtu.be links, Shorts URLs and an 11-character video ID.

Why is there no country or language selector?

The call works from the video ID alone.

Can a number come back blank?

Anything the API does not return stays blank.

Does the comment count include replies?

We show the API's figure as is; the breakdown is not known.
