在決定部落格要寫哪個關鍵字之前，會想先把幾項數字一次看清楚。輸入一個關鍵字，就會把每月搜尋量、CPC、難度、搜尋意圖整理成一列的表格。

本工具的優點

  • 四項數字一列看完。搜尋量、CPC、難度、搜尋意圖。
  • 每次約 $0.012。$1 約可查 80 次。

  • 可存成 CSV。

不適合的情境

  • 想把多個關鍵字並排比較 → 本工具一次只查一個詞。多個詞請用「查看搜尋量」或「查看關鍵字難度」。
  • CPC 的單位是美元，不會換算成新台幣。
  • 有些關鍵字的難度是空的 → 難度欄位為空的列，依 DataForSEO 的說明，是因為計算難度需要搜尋結果（SERP）的資料，只有該資料庫收錄的關鍵字才會顯示難度。範例輸入的「旅遊」有數值。日本關鍵字測試時，在別的查詢中難度為空的詞，改用另一個 API 重新輸入，結果同樣是空的（日本關鍵字的實測）。
  • 不會顯示 12 個月的變化。要看趨勢請用「查看過去每月搜尋量」。
  • 搜尋量的意義 → 表格中的每月搜尋量，接近最近 12 個月的平均值（台灣範例「旅遊」：表格為 60,500；最近 12 個月各月數值的平均約 58,900；最新一個月為 110,000），與最新一個月的數字不同。
  • 台灣市場的資料：實測（2026-11-24，台灣、繁體中文）「部落格 架設教學」「部落格」「台北 美食」沒有搜尋量資料，結果為空（仍可能計費）；「咖啡」（約 150 萬）、「旅遊」（約 6.1 萬）、「蝦皮」、「iphone 16」、「聯盟行銷」（約 1,300）、「斜槓」（約 1,900）則有資料。台灣用語可能查不到資料，建議先用較通用的詞試試。

本工具只專注在一件事：用一列看一個關鍵字的搜尋量、CPC、難度、搜尋意圖。

常見問題

搜尋意圖只會顯示一種嗎？

只顯示主要的一種。即使是混合多種意圖的詞，也是顯示最強的那一種。

CPC 的單位是什麼？

美元。是每次點擊的參考金額。

為什麼難度會是空的？

難度欄位為空的列，依 DataForSEO 的說明，是因為計算難度需要搜尋結果（SERP）的資料，只有該資料庫收錄的關鍵字才會顯示難度。範例輸入的「旅遊」有數值。日本關鍵字測試時，在別的查詢中難度為空的詞，改用另一個 API 重新輸入，結果同樣是空的（日本關鍵字的實測）。

國家與語言會影響什麼？

它決定查詢數據的市場。選擇台灣、繁體中文，就會是台灣的數字。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見什麼是 DataForSEO？。
