本工具的優點

  • 四項數字一列看完。搜尋量、CPC、難度、搜尋意圖。
  • 每次約 $0.012。$1 約可查 80 次。
  • 幾秒內回傳。畫面上實測約 1 秒。
  • 搜尋意圖是中文。
  • 可存成 CSV。

不適合的情境

  • 想把多個關鍵字並排比較 → 本工具一次只查一個詞。多個詞請用「查看搜尋量」或「查看關鍵字難度」。
  • CPC 的單位是美元，不會換算成新台幣。
  • 有些關鍵字的難度是空的 → 難度欄位為空的列，依 DataForSEO 的說明，是因為計算難度需要搜尋結果（SERP）的資料，只有該資料庫收錄的關鍵字才會顯示難度。這次輸入的 1 個詞有數值。在別的查詢中難度為空的詞，改用另一個 API 重新輸入，結果同樣是空的（實測）。
  • 不會顯示 12 個月的變化。要看趨勢請用「查看過去每月搜尋量」。
  • 搜尋量的意義 → 表格中的每月搜尋量，接近最近 12 個月的平均值（實測：5,400；各月數值的平均約 5,125），與最新一個月的數字不同。

本工具只專注在一件事：用一列看一個關鍵字的搜尋量、CPC、難度、搜尋意圖。

常見問題

搜尋意圖只會顯示一種嗎？

只顯示主要的一種。即使是混合多種意圖的詞，也是顯示最強的那一種。

CPC 的單位是什麼？

美元。是每次點擊的參考金額。

為什麼難度會是空的？

難度欄位為空的列，依 DataForSEO 的說明，是因為計算難度需要搜尋結果（SERP）的資料，只有該資料庫收錄的關鍵字才會顯示難度。這次輸入的 1 個詞有數值。在別的查詢中難度為空的詞，改用另一個 API 重新輸入，結果同樣是空的（實測）。

國家與語言會影響什麼？

它決定查詢數據的市場。選擇日本、日文，就會是日本的數字。

可以用免費信箱註冊嗎？

不行。DataForSEO 不接受免費信箱。詳情請見What is DataForSEO?（英文）。
