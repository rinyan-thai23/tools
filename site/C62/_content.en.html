Why use this tool

  • Scores and speed figures on one screen. The blog article we tried (shopify.com/blog/how-to-start-a-blog) scored 76 for performance, 92 for accessibility, 96 for best practices and 92 for SEO (measured, mobile setting).
  • Detailed figures. 3.7 seconds to first content, 4.1 seconds to the largest content, and so on (measured).
  • About $0.005 per call. Roughly 200 per $1, handy for before-and-after comparisons.
  • Save as CSV. Keep a record from before and after a fix.
  • Fixed to mobile. A fit for shops whose customers mostly use phones.

When it is not the right fit

  • Free is enough → for a one-off check, PageSpeed Insights and similar free tools do the job. This tool is for people who want a CSV record per client.
  • You want desktop scores → this tool runs with the mobile setting.
  • You want real visitors' speed → these are values measured in a test environment.
  • You expect the same score every time → scores can vary from run to run (per Google's explanation).

FAQ

What is a perfect score?

100. Lighthouse scores run from 0 to 100.

Why does the score differ a little each time?

Network conditions and other factors make each run vary. The same page can move by a few points.

How long does it take?

We measured about 25 to 30 seconds (27 seconds for the US sample; 24 to 26 seconds in an earlier test in Japan), a little longer than the other tools.

Can I choose desktop?

Not in this tool. It tests with the mobile setting.

Can I sign up with a free email address?

No. DataForSEO does not accept free email providers. See What is DataForSEO?
