營運者

Hideaki Takahashi（部落格與網站營運者）

我經營部落格與網站，也製作小工具，讓大家不必複雜的設定，就能使用工作上需要的資料。

我做的東西

為企業用戶（B2B）打造的簡單單一功能工具。每個工具只做一件事：輸入一個值、按下執行，結果會以表格與 CSV 檔案呈現。

  • BYOK（自備 API 金鑰）。沒有月費，只需向 DataForSEO 支付實際使用的費用。
  • 您輸入的 API 金鑰只會儲存在您自己的瀏覽器中。
  • 多數工具附有免費範例，執行前就能先看到結果的樣子。

我營運的網站

  • DataForSEO 單一功能工具集（{{SITE_URL}}）：把 DataForSEO 的功能做成一個功能一個畫面。提供日文、英文、繁體中文、越南文與印尼文。

之後有新網站，會在這裡補充。

推薦（聯盟）連結

我打算對 DataForSEO 等服務使用推薦連結。目前尚未申請，也尚未設定任何推薦計畫。等到有計畫核准本站後，我會更新此頁。

揭露聲明：「本頁含有推薦連結。若您透過這些連結購買，我可能會獲得佣金。」

有（或將會有）推薦連結的頁面

  • 首頁：標題中的「DataForSEO」連結
  • 所有工具頁面的頁尾：「建立 DataForSEO 帳號」
  • 什麼是 DataForSEO？：註冊指南

設定推薦連結後，連結旁會顯示「（推薦連結）」，且連結帶有 rel="sponsored"。

我的原則

  • 工具的表格只顯示 API 回傳的值。我不會為了賺取佣金而自創排名或分數。
  • 即使不透過推薦連結，自行建立 DataForSEO 帳號，所有工具的使用方式也完全相同。
  • 本站並非 DataForSEO 官方網站。
