Tentang pengelola dan keterbukaan tautan referral

Pengelola

Hideaki Takahashi (pengelola blog dan situs web)

Saya mengelola blog dan situs web. Saya membuat alat-alat kecil supaya orang bisa memakai data untuk pekerjaan tanpa pengaturan yang rumit.

Apa yang saya buat

Alat satu fungsi yang sederhana untuk pengguna bisnis (B2B). Setiap alat hanya melakukan satu hal: masukkan sebuah nilai, jalankan, lalu terima hasilnya dalam bentuk tabel dan berkas CSV.

  • BYOK (bawa kunci API sendiri). Tidak ada biaya bulanan; kamu hanya membayar DataForSEO sesuai pemakaian.
  • Kunci API yang kamu masukkan hanya disimpan di browser kamu sendiri.
  • Sebagian besar alat punya contoh gratis, jadi kamu bisa melihat bentuk hasilnya sebelum menjalankan apa pun.

Situs yang saya kelola

  • Alat DataForSEO ({{SITE_URL}}): fitur DataForSEO, satu layar untuk satu fitur. Tersedia dalam bahasa Jepang, Inggris, Mandarin Tradisional, Vietnam, dan Indonesia.

Saya akan menambahkan situs lain di sini saat sudah diluncurkan.

Tautan referral (afiliasi)

Saya berencana memakai tautan referral untuk layanan seperti DataForSEO. Saat ini belum ada pendaftaran maupun pengaturan program referral apa pun. Saya akan memperbarui halaman ini setelah ada program yang menyetujui situs ini.

Keterbukaan: “Halaman ini berisi tautan referral. Jika kamu membeli lewat tautan tersebut, saya bisa mendapat komisi.”

Halaman yang memiliki (atau akan memiliki) tautan referral

  • Beranda: tautan “DataForSEO” di judul
  • Bagian bawah setiap halaman alat: “Buat akun DataForSEO”
  • Apa itu DataForSEO?: panduan mendaftar

Setelah tautan referral diatur, tulisan “(tautan referral)” akan muncul di samping tautannya, dan tautan itu membawa rel="sponsored".

Aturan saya

  • Tabel di alat hanya menampilkan nilai yang dikembalikan API. Saya tidak mengarang peringkat atau skor demi mendapat komisi.
  • Kamu bisa memakai semua alat dengan cara yang sama tanpa tautan referral, dengan membuat akun DataForSEO sendiri.
  • Situs ini bukan situs resmi DataForSEO.
