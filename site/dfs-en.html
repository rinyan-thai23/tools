What is DataForSEO?

In one sentence

A service that lets you pull "SEO data" — search results, ads, keywords and more — through an API. Think of it as the data supplier behind many SEO tools.

The tools on this site turn DataForSEO's features into screens, one feature per tool. They show the returned data as-is, in a table.

What can you do with it?

  • Search results (SERP): rankings and content from Google search, maps, news, images and more
  • Keywords: search volume, related keywords and more
  • Site analysis: backlinks, technologies used by a site and more
  • Business data: reviews and basic info for shops and companies

Each tool page explains what it does. Pick one from the tool list.

How pricing works

  • Pay as you go. There is no fixed monthly fee.
  • You top up your balance in advance, and each request deducts from it.
  • Each tool page shows an approximate cost per request, and the screen shows the actual cost used.
  • For the latest top-up terms, check the official DataForSEO site.

Before you sign up

Free email addresses (Gmail, Yahoo Mail, etc.) cannot be used to register.
Use a company or your own domain email address.
  • You enter two things in the tools: your login email and your API password.
  • The API password is on the "API Access" page of your dashboard. It is different from your login password.
  • The key is stored only in your browser. It is never sent to this site's server.

Getting started

  1. Create a DataForSEO account
  2. Find your API password under "API Access" in the dashboard
  3. On the top page, enter your email and API password and save
  4. Open any tool, look at the sample first, then run a real search
